# Порт: fix(ChatMessage): show actions on focus and align them in RTL (#7245)

**Upstream:** `1ec725ba83601625e94269f226854d9ca0e806d3` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

Тема `chat-message`: слот `actions` остаётся видимым при `focus-within` (раньше действия
появлялись только по hover и были недоступны с клавиатуры), для `side: right` вместо
`right-0` используется логическое `end-0` (корректно в RTL), слот `files` получил `flex-wrap`.

## Как перенесено

Три точечные правки в `src/theme/chat-message.ts`. В форке строки слотов собраны иначе
(`actions` — массив с `transition-opacity` через `join`), поэтому правился только нужный фрагмент.
Снапшоты `ChatMessage` и `ChatMessages` (обе проектные конфигурации) обновлены.
