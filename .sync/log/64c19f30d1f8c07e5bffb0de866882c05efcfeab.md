# Порт: feat(ChatMessage): add `part` slot (#7251)

**Upstream:** `64c19f30d1f8c07e5bffb0de866882c05efcfeab` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

`ChatMessage` получает слот `part` (`{ part, index, message }`): вызывается для каждой части сообщения, не отрисованные части падают в вывод по умолчанию; игнорируется при использовании слота `content`. Текстовые части теперь оборачиваются в `<span data-slot="text">` с новым слотом темы `text: 'whitespace-pre-wrap'`. В `ChatMessages` слоты считаются по `SlotsBase<T>` (типы части сообщения берутся из дженерика списка). Документация и примеры переведены с `#content` на `#part`.

## Как перенесено

- `src/runtime/components/ChatMessage.vue` — слот `part`, `isTextPart`, `hasContent`, `<span data-slot="text">`. Ветки `props.content` апстрима не переносились: в b24ui свойство `content` не отрисовывается (помечено deprecated, §2), поэтому `hasContent` без него.
- `src/theme/chat-message.ts` — слот `text: 'whitespace-pre-wrap'`.
- `src/runtime/components/ChatMessages.vue` — тип `SlotsBase<T>` и его использование в `ChatMessagesSlots`.
- Тест `part` из апстрима добавлен в `test/components/ChatMessage.spec.ts`; снапшоты `ChatMessage*` и `ChatMessages*` обновлены только новым `<span data-slot="text" class="whitespace-pre-wrap">`.
- Документация: `chat.md` (клиентский пример на `#part` с `MDC`, примечание про слот), `chat-messages.md` (пример в tip), примеры `ChatPaletteContentSearchExample`, `ChatPaletteModalExample`, `SidebarChatExample` — по образцу апстрима, `b24ui: { text: … }` вместо `ui`.
- Не переносилось (в форке нет файлов): `docs/app/components/chat/Chat.vue`, `ThemeStudioViewChat.vue`, `playgrounds/nuxt/app/pages/chat.vue`, `skills/…/layouts/chat.md`.
