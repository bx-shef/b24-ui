# Порт: fix(prose): size inline code in headings without anchor links (#7291)

**Upstream:** `ce2cee02a2b681dd265d3d8340937d3b329bee52` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

В темах `prose/h2` и `prose/h3` селектор размера и жирности инлайн-кода `[&>a>code]` заменён на `[&_code]`: код в заголовке без ссылки-якоря (например, при отключённых якорях) тоже получает размер заголовка.

## Как перенесено

- `src/theme/prose/h2.ts`, `src/theme/prose/h3.ts` — `[&>a>code]:text-(length:…)` → `[&_code]:text-(length:…)`. Классы b24ui другие (токены `--ui-font-size-*`), `font-bold` у нас в теме нет — заменён только селектор. Ховер-классы (`hover:[&>a>code]`) остались на `a>code`, как в апстриме.
- `prose/h4` в апстриме не менялся (правила для code там нет), у нас тоже оставлен как был.
- Снапшоты prose-тестов не изменились.
