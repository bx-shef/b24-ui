# Порт: fix(utils): only match `null` with `null` in `compare`

**Апстрим:** `073be5e6a323c706a97039a749c7bebc27ebe029` (nuxt/ui)
**Решение:** port

`utils/index.ts`: перед ветками string/comparator/get добавлена `if (value === null || currentValue === null) return value === currentValue` — иначе comparator-функция/`get(value, by)` сопоставляли `null` с элементом-«label» (`get(item,'value')` → undefined, `get(null,'value')` → undefined, равны). Тесты апстрима ложились в блоки `describe('compare')`/`getDisplayValue`, которых в нашем `test/utils/index.spec.ts` нет, поэтому два теста добавлены отдельным блоком.
