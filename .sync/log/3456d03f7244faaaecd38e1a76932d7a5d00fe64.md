# Порт: docs: disable server sourcemaps in dev

**Upstream:** `3456d03f7244faaaecd38e1a76932d7a5d00fe64` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

`sourcemap.server: false` вынесен из `$production` на верхний уровень конфига документации: в dev пересборка Nitro после сохранения двух файлов темы доходила до 4,7 ГБ и падала по памяти, без sourcemap — 1,6 ГБ.

## Как перенесено

То же в `docs/nuxt.config.ts`: у нас `$production` содержал только этот ключ, блок убран целиком.
