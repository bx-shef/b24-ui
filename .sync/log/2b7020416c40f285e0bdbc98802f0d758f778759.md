# Порт: perf(Button): skip the link when there is no `to` or `href` (#7221)

**Upstream:** `2b7020416c40f285e0bdbc98802f0d758f778759` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

Кнопка без `to`/`href` больше не создаёт полноценный `Link` (с его setup и работой с роутером).
Вместо него рендерится функциональный компонент `LinkSlot`, который отдаёт в слот те же props,
что и `Link`, а единственный дочерний узел возвращает как есть (`$el` остаётся элементом).

## Как перенесено

- `src/runtime/utils/link.ts`: добавлен `LinkSlot` (1:1).
- `Button.vue`: `isLink` + `<component :is="isLink ? B24Link : LinkSlot">`. В форке корневой
  компонент называется `B24Link`, а привязка ссылочных props уже вынесена в `proxyLinkProps`
  (там остаётся комментарий про `omit` в docs для vue) — их не трогали.
- Снапшоты не менялись: разметка идентична. Проверены `Button.spec.ts` и `test/utils/link*`.
