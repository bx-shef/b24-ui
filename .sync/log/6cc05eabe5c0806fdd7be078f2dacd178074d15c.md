# Порт: fix(ai): stop `isToolStreaming` on denied approvals (#7243)

**Upstream:** `6cc05eabe5c0806fdd7be078f2dacd178074d15c` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

`isToolStreaming` считал tool-part в состоянии `approval-responded` потоковой даже после отказа
пользователя, хотя инструмент уже не запустится. Теперь для `approval-responded` результат
`approval?.approved !== false`.

## Как перенесено

1:1 в `src/runtime/utils/ai.ts` (расширена сигнатура и jsDoc). В `src/` по-прежнему только
типы из `ai`; новый `test/utils/ai.spec.ts` перенесён без изменений (чистая функция, без компонентов).
