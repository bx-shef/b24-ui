## Изменение в апстриме

Каталог поднимает `vitest` до `^5.0.5`. В v5 `bench`/`describe` из `vitest` для бенчмарков убраны: бенчмарк — это `test(name, async ({ bench }) => { await bench(name, fn).run() })`, проект бенчмарков называется `vue (bench)`. Скрипт `bench` и резолвер путей снапшотов (`.bench.ts`) подправлены; бенчи переписаны на новое API.

## Как перенесено

- `pnpm-workspace.yaml`: `vitest: ^5.0.5`. Закрепление `@vitest/coverage-v8` (у нас оно было, у апстрима — нет) поднято с `4.1.11` до `5.1.1` — версия, которую резолвит `vitest` (иначе пакеты расходятся по мажору). `pnpm install` и `pnpm install --frozen-lockfile` проходят.
- `package.json`: `bench` → `vitest bench --project 'vue (bench)'`.
- `vitest.config.ts`: `resolveSnapshotPath` понимает `.bench.ts`.
- `test/bench/*.bench.ts` (включая наш `search.bench.ts`, которого нет в апстриме) переписаны на фикстуру `bench`; обёрток для CodSpeed (`CYCLES`, ленивый `wrapper ??=`, `tableBench`) не добавляли — CodSpeed у нас нет (см. cb5271a), `setup`/`teardown` заменены монтированием внутри теста.
- Проверено: `pnpm run bench --run` — 5 файлов, 20 тестов зелёные; `Button`, `Select` и др. спеки зелёные, снапшоты не менялись.
