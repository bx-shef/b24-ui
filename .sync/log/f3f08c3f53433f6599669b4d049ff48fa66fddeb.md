# skip — nuxt/ui@f3f08c3f53433f6599669b4d049ff48fa66fddeb

**Upstream:** chore(deps): update nuxt framework to ^4.7.0 (#7486)

**Decision:** skip (версии не менялись).

Бамп `nuxt`, `@nuxt/kit`, `@nuxt/schema` до `^4.7.0` ломает `pnpm run docs:generate`:
при prerender в чанке `parser-*.mjs` (бандл `yaml@2.9.0` из @nuxt/content/mdc)
остаётся голый `require("process")` без шима `__require`, SSR падает с
`require is not defined in ES module scope`, 156 маршрутов отдают 500. На
`nuxt@4.6.4` тот же чанк использует `__require` и сборка проходит. Проверено
бисекцией: `8f68c0ea` (4.6.4) зелёный, то же дерево с одним бампом nuxt — красный;
`lint`, `typecheck`, `test`, `build` при этом зелёные.

Решение владельца: остаёмся на `^4.6.4` (catalog и override `@nuxt/kit` в
`pnpm-workspace.yaml`, lock как на `fork/main`). Расхождение записано как
исключение в `.sync/dep-parity.json` (`package.json`: nuxt, @nuxt/kit,
@nuxt/schema; `docs/package.json` и `playgrounds/nuxt/package.json`: nuxt).
Вернуться к `^4.7.0`, когда чанк перестанет ломаться (проверять `docs:generate`).
Бамп был закоммичен отдельно (18f95c33) и откатом этим же PR.
