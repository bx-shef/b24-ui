# 1e391c82 — fix(module): локали `@nuxtjs/i18n` со script-субтегом

**Решение:** port.

В апстриме `resolveLocaleKey` получает кандидатов «тег и тег без скрипта». У форка `resolveLocaleKey` устроен иначе (сопоставляет с объявленными тегами локалей `getLocaleTags`, а не с ключами), поэтому намерение перенесено по месту: в `src/utils/locales.ts` для каждого запрошенного тега добавлен вариант без четырёхбуквенного субтега скрипта. Ожидания тестов подстроены под наши ключи (`zh-Hant-TW` → `tc`, `zh-Hans-CN` → `sc`, `pt-Latn-BR` → `br`; `zh-Hant` без региона остаётся без совпадения). Новые тесты красные без правки.
