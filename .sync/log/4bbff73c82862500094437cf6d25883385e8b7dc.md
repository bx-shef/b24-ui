# Порт: fix(ChatPromptSubmit): queue instead of stopping while the prompt has text

**Апстрим:** `4bbff73c82862500094437cf6d25883385e8b7dc` (nuxt/ui)
**Решение:** port

- `utils/chat.ts`: ключ внедрения `chatPromptQueueingInjectionKey` (`Symbol('bitrix24-ui.chat-prompt-queueing')` — префикс форка, как у остальных ключей).
- `ChatPrompt.vue`: `provide(...)` — «отправка из промпта сейчас встанет в очередь» (`isBusy`, `v-model:queue` задан, есть текст или файлы).
- `ChatPromptSubmit.vue`: `currentStatus` (внутри такого промпта — `ready`), от него `disabled`, `statusButtonProps`, `ariaLabel`.
- **Reka UI props (AGENTS.md):** `ChatPromptSubmit` брал `useForwardProps` из `reka-ui`, который отфильтровывает значения, пришедшие только из `<B24Theme :props>`; переведён на локальный `composables/useForwardProps`. Новый `test/components/ThemeForwardProps.spec.ts` проверяет, что `size` из `Theme :props` доходит до кнопки (разметка совпадает с явным `size="xs"` и отличается от значения по умолчанию).
- Тесты `ChatPrompt.spec.ts` перенесены; наши подписи — `Send`/`Stop generating` (en-локаль форка), а не `Send prompt`.
- Docs (по-русски): в «Очередь» дописано про `ChatPromptSubmit` внутри промпта.
