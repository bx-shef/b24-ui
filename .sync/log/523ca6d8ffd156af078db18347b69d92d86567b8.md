# Пропуск: fix(LocaleSelect): show Tajikistan flag for the Tajik locale (#7237)

**Upstream:** `523ca6d8ffd156af078db18347b69d92d86567b8` (nuxt/ui)
**Decision:** n/a

## Изменение в апстриме

В таблицу `languageToCountry` внутри `LocaleSelect.vue` (и в docs-компонент `SupportedLanguages.vue`)
добавлено соответствие `tg` → `tj`, чтобы для таджикской локали показывался флаг Таджикистана.
Добавлен `test/components/locale/LocaleSelect.spec.ts`.

## Почему n/a

В форке нет таджикской локали (`src/runtime/locale/tg.ts`) и она не добавляется: набор локалей
форка курируется отдельно (PORTING.md §2, «Locales — do NOT add new ones»). Таблица флагов в
`LocaleSelect.vue` у форка своя и содержит только его локали, а в docs форка этот компонент лежит
по другому пути (`docs/app/components/SupportedLanguages.vue`) и тоже перечисляет только локали форка. Без локали `tg` правка бессмысленна; тест апстрима не переносился.
