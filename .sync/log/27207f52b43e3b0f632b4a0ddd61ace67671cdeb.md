# Порт: feat(Select/SelectMenu/InputMenu): add `item` to trigger slots

**Апстрим:** `27207f52b43e3b0f632b4a0ddd61ace67671cdeb` (nuxt/ui)
**Решение:** port

- `utils/index.ts`: `findItem()`, `getSelectedItem()` (выбранный элемент по `valueKey`/`by`, `multiple` — массив; без `valueKey` объект вне `items` сохраняется), `getDisplayValue()` теперь через `findItem()`. `types/utils.ts`: `GetSelectedItem`.
- `Select`, `SelectMenu`, `InputMenu`: слоты `leading`/`default`/`trailing` получают `item` (`resolveSelectedItem()` вызывается только когда слот передан; в `InputMenu` в режиме autocomplete ничего не выбрано). Типы слотов — общий `TriggerSlotProps`; у нас слот-проп `b24ui`, не `ui` (§1).
- Иконок/`:is` из данных коммит не добавляет: `item` — просто данные; `item.icon` в плейграунде идёт под `v-if` и только из локальных `statuses`. Сторож `unsafe-icon-bindings.spec.ts` зелёный.
- Docs (по-русски): примеры `SelectFetchExample`, `SelectItemsChipExample` переведены на `item` (убраны вспомогательные `getUserAvatar`/`getChip`), заметки о `item` в select/select-menu/input-menu, правки подсказок «С иконкой/аватаром/чипом в элементах». Якоря не менялись.
- Плейграунды: добавлен случай со слотом `item` в `select.vue` у `nuxt` и `demo` (у апстрима ещё `select-menu`/`input-menu` — у нас эти страницы устроены иначе, отдельный случай не добавлялся).
- Тесты: `Select/SelectMenu/InputMenu.spec.ts` ложатся без правок, `findItem`/`getSelectedItem` — в `test/utils/index.spec.ts`.
