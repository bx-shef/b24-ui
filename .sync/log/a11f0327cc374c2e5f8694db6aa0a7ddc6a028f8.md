# Порт: fix(Stepper): announce current step from 1 (#7342)

**Апстрим:** `a11f0327cc374c2e5f8694db6aa0a7ddc6a028f8` (nuxt/ui)
**Решение:** port

## Что сделал апстрим
Reka UI нумерует шаги с 1, а `currentStepIndex` — индекс с 0, поэтому скринридер объявлял «Step 0 of 3». Добавлен `rootStep = currentStepIndex + 1` для `v-model` корня, `:step="count + 1"` у элементов.

## Порт в b24ui
Добавлен `rootStep` поверх нашего `currentStepIndex` — инвариант §2 (правило слота для числовых значений и `valueKey`) не тронут, `currentStepIndex` как был. Тесты из апстрима перенесены. Снимки Stepper обновлены ровно в тех же 54 строках, что и у апстрима (меняются только `aria-*`/номера шагов): это следствие самой правки, а не «подгонка под компиляцию».
