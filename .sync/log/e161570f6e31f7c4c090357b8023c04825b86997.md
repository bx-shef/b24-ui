# Port: feat(Toggle/ToggleGroup): new components (#7364)

**Upstream:** `e161570f6e31f7c4c090357b8023c04825b86997` (nuxt/ui)
**Decision:** port — новые компоненты, с адаптацией под Button форка

## Что в апстриме

`Toggle` (кнопка с нажатым/отжатым состоянием) и `ToggleGroup` (набор таких кнопок, `single`/`multiple`, `attached`, вертикальная ориентация) поверх `Button` и Reka UI.

## Отличия форка

- У Button форка нет `variant`/`activeVariant` (есть `color`/`activeColor`, устаревшие `depth`/`activeDepth` исключены), поэтому пропсы `variant`/`activeVariant` не переносятся. Умолчания: `color` — `air-secondary-no-accent`, `activeColor` — `air-primary` (как в Pagination); задаются в computed, чтобы `<B24Theme :props>` не перебивался.
- `attached`: у Button форка скругление через `group-[.is-field-group]/items`, а Reka рисует скрытый input после элементов. Поэтому тема считает скругление сама по `*-of-type` (`--ui-btn-radius`), внешний FieldGroup сбрасывается через `fieldGroupInjectionKey`.
- Слоты передают `{ b24ui }`, пропс `b24ui`, `data-slot`, `useForwardProps` из composables форка.
- Иконки в тестах/плейграундах — компоненты `@bitrix24/b24icons-vue`.
