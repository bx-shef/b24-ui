# 422d015e — fix(EditorToolbar): состояние нажатия у кнопок форматирования

**Решение:** port.

`getButtonProps()` в `EditorToolbar.vue` отдаёт `aria-pressed` кнопкам видов `mark`, `heading`, `textAlign`, `blockquote`, `bulletList`, `orderedList`, `taskList`, `codeBlock`, `link` (значение `isActive(item)`; для `link` при частично ссылочном выделении — `'mixed'`). Выпадающие меню и кнопки вроде `undo` атрибута не получают. Перенос 1:1 (у форка есть `isActive`, `props.editor`), тест — на настоящем `Editor` с `StarterKit`, снимки EditorToolbar обновлены.
