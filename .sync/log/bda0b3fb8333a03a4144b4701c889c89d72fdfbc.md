# Порт: perf(Button): read the link props in one pass (#7239)

**Upstream:** `bda0b3fb8333a03a4144b4701c889c89d72fdfbc` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

Вместо `pickLinkProps` + `useForwardProps` + `omit` (три прохода по ключам через прокси
`useComponentProps`) кнопка собирает ссылочные props за один цикл по `linkKeys`,
пропуская `type`, `disabled`, `onClick` (они биндятся отдельно).

## Как перенесено

`Button.vue`: цикл по `linkKeys` в существующем computed `proxyLinkProps` (в форке он так назван).
Убраны ставшие ненужными импорты `useForwardProps`, `omit`, `pickLinkProps`; вместе с `omit`
ушёл и `@memo` про его отсутствие в экспорте docs (vue). `pickLinkProps` остаётся в `utils/link.ts`
для остальных компонентов. Снапшоты не менялись; `Button.spec.ts` и `test/utils/link*` зелёные.
