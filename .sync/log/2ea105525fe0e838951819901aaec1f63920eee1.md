# Порт: fix(locale): let each locale order the prose collapse labels

**Апстрим:** `2ea105525fe0e838951819901aaec1f63920eee1` (nuxt/ui)
**Решение:** port

- `types/locale.ts`: у `prose.codeCollapse` и `prose.collapsible` новое сообщение `label`.
- `CodeCollapse.vue`, `Collapsible.vue`: подпись собирается `t('…label', { text, name })`, а не склейкой «текст имя».
- Все наши 20 локалей получили `label`. Где апстрим менял порядок — повторено по смыслу на наших строках: `de`, `in`, `kz`, `tr` — `{name} {text}` (де/кз/тр — глагол строчной, имя объекта в нужной форме: `Кодты`, `Қасиеттерді`, `Kodu`, `Özellikleri`), `ja` — `{name}を{text}`, `sc`/`tc` — `{text}{name}`, остальные `{text} {name}`; `fr` — `le code`/`les propriétés`; `ar` — определённый артикль (`الرمز`, `الخصائص`; наши прежние слова сохранены, у апстрима «الكود»). Эти переводы собраны вручную по образцу апстрима; носителем языка не вычитаны.
- Тесты `CodeCollapse.spec.ts` / `Collapsible.spec.ts` перенесены; ключ контекста локали — `bitrix24-ui.locale-context`, ожидаемые японские строки — по нашему `ja` («コードを表示»).
