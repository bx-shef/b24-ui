# Порт: fix(SelectMenu): allow keyboard navigation with search input autofocus disabled (#7212)

**Upstream:** `61cc832f587786144cac5ad2c05c4e8f3eeb9ffc` (nuxt/ui)
**Decision:** port

## Изменение в апстриме

При `searchInput: { autofocus: false }` фокус не попадал внутрь меню, и клавиатурная навигация
по списку не работала (listbox навигирует только от поля поиска). Теперь:
- `onMountAutoFocus` при отключённом автофокусе фокусирует сам `FocusScope` (без виртуальной
  клавиатуры на touch-устройствах);
- новый `onFocusScopeKeydown` пробрасывает `down/up/home/end` в поле поиска, если фокус на самом scope;
- слот `focusScope` получил `focus:outline-none`.

## Как перенесено

- `SelectMenu.vue` и `src/theme/select-menu.ts`: 1:1, `ui` → `b24ui` не затрагивалось.
- Селектор поля поиска оставлен локальный: `input[data-slot="input"]` (в форке `data-slot` стоит
  на самом `<input>`, а не на обёртке — см. комментарий в `test/components/SelectMenu.spec.ts`).
  Апстримовский `[data-slot="input"] input` ничего бы не нашёл.
- Тесты: добавлена проверка, что фокус внутри `focusScope`, и новый кейс навигации с клавиатуры
  (через `openWith({ autofocus: false })`; значения `Option 1/2`). Снапшоты SelectMenu обновлены
  (изменился только класс `focus:outline-none` на `focusScope`).
