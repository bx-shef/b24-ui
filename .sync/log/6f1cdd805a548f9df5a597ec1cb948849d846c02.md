# Port: perf(module): stop recompiling templates on every file change

**Upstream:** `6f1cdd805a548f9df5a597ec1cb948849d846c02` (nuxt/ui, #7304)
**Decision:** port

## Что в апстриме

Шаблоны, зависящие только от опций модуля, получают `dependsOn: []`; `ui.css` при `experimental.componentDetection` — функцию `dependsOn` (файлы слоёв); хук `builder:watch` с `updateTemplates` удалён.

## Перенос

Те же `dependsOn` на шаблонах `b24ui/*`, `b24ui/prose/index.ts`, `b24ui.static.css`, `b24ui/index.ts`, `types/b24ui.d.ts`, `b24ui-image-component.ts` и плагине `b24ui-i18n.mjs`; `b24ui.css` — функция по `COMPONENT_DETECTION_WATCH_RE` (общий список расширений с обходом файлов остался). Нужен `@nuxt/kit` 4.6.x: `dependsOn` есть в установленной 4.6.4.

**Расхождение (§2).** Сторож `watchForComponentDetection` и `isCssTemplate` удалены: на них держался инвариант «имя CSS-шаблона — одна константа» (#80); теперь имя пишется один раз в `CSS_TEMPLATE_FILENAME`, а регрессию держит новый блок `regeneration on file changes` (тест апстрима, адаптированный: `b24ui.css`, наш `getTemplates(options, nuxt, resolve)`). Старые тесты сторожа заменены. Инвариант в PORTING.md §2 переписан.
