## Что такое LLMs.txt? {#what-is-llmstxt}

LLMs.txt — структурированный формат документации, созданный специально для больших языковых моделей (LLM). Файлы LLMs.txt от Bitrix24 UI содержат исчерпывающую информацию о библиотеке компонентов, и ИИ-инструментам проще понять Bitrix24 UI и помогать в разработке.

Файлы оптимизированы для работы с ИИ и содержат структурированные сведения о компонентах, API, сценариях использования и лучших практиках.

## Доступные маршруты {#available-routes}

Доступ ИИ-инструментов к документации обеспечивают маршруты LLMs.txt:

- **`/llms.txt`** — структурированный обзор всех компонентов со ссылками на их документацию (~5 тыс. токенов)
- **`/llms-full.txt`** — полная документация: детали реализации, примеры, темы, композаблы и руководство по миграции (~1 млн токенов и больше)

## Какой файл выбрать {#choosing-the-right-file}

::note
**Большинству пользователей стоит начать с `/llms.txt`**: в нём вся основная информация, и он помещается в обычное контекстное окно LLM.

`/llms-full.txt` нужен, только если требуются подробные примеры реализации и ваш ИИ-инструмент поддерживает большой контекст (200 тыс. токенов и больше).
::

## Важные замечания {#important-usage-notes}

::warning
**Символ @ нужно вводить вручную.** В Cursor и Windsurf символ `@` печатают в чате руками. Если его вставить из буфера обмена, инструмент не распознает его как ссылку на контекст.
::

## Использование с ИИ-инструментами {#usage-with-ai-tools}

### Cursor

Специальные файлы LLMs.txt от Bitrix24 UI можно указывать в Cursor, чтобы ИИ лучше помогал разрабатывать компоненты.

#### Как использовать: {#how-to-use}

1. **Прямая ссылка**: укажите URL файлов LLMs.txt в вопросе
2. Добавьте эти URL в контекст проекта через `@docs`

[Подробнее о промптах и упоминаниях `@` в Cursor](https://cursor.com/docs/agent/prompting)

### Windsurf

Windsurf умеет напрямую обращаться к файлам LLMs.txt Bitrix24 UI, чтобы разобраться в использовании компонентов и лучших практиках.

#### LLMs.txt в Windsurf: {#using-llmstxt-with-windsurf}

- Ссылайтесь на нужные URL LLMs.txt через `@docs`
- Создайте в рабочем пространстве постоянные правила, которые ссылаются на эти URL

[Подробнее о Windsurf Web and Docs Search](https://docs.windsurf.com/windsurf/cascade/web-search)

### Другие ИИ-инструменты {#other-ai-tools}

Любой ИИ-инструмент с поддержкой LLMs.txt может использовать эти маршруты, чтобы лучше понимать Bitrix24 UI.

#### Примеры для ChatGPT, Claude и других LLM: {#examples-for-chatgpt-claude-or-other-llms}

- «Используй документацию Bitrix24 UI с https://bitrix24.github.io/b24ui/llms.txt»
- «Следуй полным рекомендациям Bitrix24 UI с https://bitrix24.github.io/b24ui/llms-full.txt»
