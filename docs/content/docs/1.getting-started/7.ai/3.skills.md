## Что такое навыки? {#what-are-skills}

Навыки (skills) — это структурированные файлы знаний, которые дают AI-агентам для кода контекст о библиотеке, фреймворке или кодовой базе. В отличие от MCP-серверов, которые дают доступ к инструментам в реальном времени, навыки загружаются прямо в контекст агента, и он может обращаться к ним на протяжении всего разговора.

Bitrix24 UI предоставляет **навык использования**, который учит AI-агентов создавать интерфейсы на Bitrix24 UI: установка, темы, компоненты, композаблы, формы, оверлеи и раскладки.

## Использование {#usage}

Навык использования даёт AI-агентам исчерпывающие знания о разработке на Bitrix24 UI v2. Он охватывает:

- установку для Nuxt, Vue, Laravel и AdonisJS
- темы и брендинг на семантических цветах и CSS-переменных
- все 130+ компонентов с пропсами и сценариями использования
- композаблы (`useDevice`, `useToast`, `useOverlay`, `defineShortcuts`, `useConfetti`, `useSpeechRecognition`)
- валидацию форм через Standard Schema
- компоновку раскладок (Dashboard)
- официальные стартовые шаблоны

В навык входят дополнительные справочники, которые AI-агент загружает по мере необходимости в зависимости от задачи. Ответы остаются точными, а контекст расходуется экономно.

::note
После установки навык вызывается командой `/b24-ui-nuxt` в чате агента.
::

### Skills CLI

Проще всего установить навык Bitrix24 UI через CLI [`skills`](https://skills.sh). Он поддерживает больше 35 агентов, среди них Cursor, Claude Code, Codex, Windsurf и Cline.

```bash
npx skills add bitrix24/b24ui
```

Конкретных агентов можно указать флагом `--agent`:

```bash
npx skills add bitrix24/b24ui --agent cursor
npx skills add bitrix24/b24ui --agent claude-code
```

Или установить глобально, чтобы навык был доступен во всех проектах:

```bash
npx skills add bitrix24/b24ui --global
```

::tip
На [skills.sh](https://skills.sh) можно узнать больше об экосистеме навыков и посмотреть доступные навыки.
::

### Cursor

#### Быстрая установка {#quick-install}

Нажмите кнопку ниже, чтобы установить навык Bitrix24 UI прямо в Cursor:

::b24-button
---
to: "cursor://anysphere.cursor-deeplink/install-skill?url=https://github.com/bitrix24/b24ui/tree/main/skills/b24-ui-nuxt"
label: Установить навык
color: air-primary
---
::

#### Ручная установка {#manual-setup}

1. Откройте Cursor и перейдите в «Settings» > «Skills»
2. Нажмите «Add skill» и введите такой URL:

```
https://github.com/bitrix24/b24ui/tree/main/skills/b24-ui-nuxt
```

### Claude Code

::note{iconName="InfoCircleIcon"}
**Убедитесь, что Claude Code установлен.** Как его установить, описано в [документации Anthropic](https://docs.anthropic.com/en/docs/claude-code/quickstart).
::

Добавьте навык командой CLI:

```bash
claude skill add https://github.com/bitrix24/b24ui/tree/main/skills/b24-ui-nuxt
```
