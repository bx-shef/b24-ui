## Что такое MCP? {#what-is-mcp}

MCP (Model Context Protocol) — открытый протокол, по которому AI-ассистенты получают доступ к внешним данным и инструментам. У Bitrix24 UI есть свой MCP-сервер. Подключите его к Claude Code, Cursor, VS Code или другому ассистенту, и тот сможет сам искать компоненты, читать их пропсы, примеры и документацию, а также находить иконки Битрикс24.

| | |
|---|---|
| Адрес | `https://b24-ui.bx-shef.by/mcp/` |
| Транспорт | HTTP (Streamable HTTP) |
| Авторизация | не нужна |

::note
Если открыть `https://b24-ui.bx-shef.by/mcp/` в браузере, сервер ответит `405 Method Not Allowed`. Так и должно быть: MCP-клиенты обращаются к нему запросами `POST`.
::

## Инструменты {#available-tools}

Инструменты ассистент вызывает сам, когда они нужны для ответа.

### Компоненты {#component-tools}

- **`b24-ui-search-components`** — поиск компонентов по имени, категории или задаче. Понимает названия из других библиотек: «segmented control» найдёт `FieldGroup`, «combobox» — `InputMenu`, «dialog» — `Modal`. Результаты отсортированы по релевантности.
- **`b24-ui-get-component`** — документация компонента. Параметр `sections` (`usage`, `examples`, `api`, `theme`, `changelog`) возвращает только нужные разделы.
- **`b24-ui-get-component-metadata`** — пропсы, слоты и события компонента без текста документации. По умолчанию пропсы в кратком виде, `full: true` даёт полные схемы (они большие).

### Композаблы {#composable-tools}

- **`b24-ui-search-composables`** — поиск композаблов (`useToast`, `useOverlay` и др.) по подстроке в имени, заголовке и описании. Без `search` — все композаблы.

### Документация {#documentation-tools}

- **`b24-ui-search-documentation`** — поиск страниц документации по заголовку, описанию или разделу. Без параметров — все страницы.
- **`b24-ui-get-documentation-page`** — Markdown страницы по её пути (`path` из результатов поиска). Параметр `headings` возвращает только нужные разделы второго уровня.
- **`b24-ui-get-migration-guide`** — руководство по переходу с прошлой мажорной версии Bitrix24 UI.

### Примеры и шаблоны {#example-tools}

- **`b24-ui-list-examples`** — имена всех примеров.
- **`b24-ui-get-example`** — исходный код примера по имени.
- **`b24-ui-list-templates`** — стартовые шаблоны; параметр `framework` отбирает шаблоны одного фреймворка.
- **`b24-ui-get-template`** — описание шаблона, его возможности и ссылки (демо, репозиторий, деплой).

### Иконки Битрикс24 {#icon-tools}

Иконки берутся из коллекции Iconify [`bx24`](https://b24-icons.bx-shef.by) (пакет `@bxshefby/icons-json`). Это те же иконки, что в `@bitrix24/b24icons-vue`, но с именами-строками.

- **`b24-ui-search-icons`** — поиск иконок по-русски («корзина», «галочка»), по-английски («trash», «check»), по теме и по старому имени компонента («CheckLIcon»). Возвращает группы иконок: имя в формате `i-bx24-{набор}-{имя}`, картинку для предпросмотра, все варианты (наборы и размеры), темы и старые имена компонентов.
- **`b24-ui-get-icon`** — одна иконка: SVG (цвет `currentColor`), варианты, ссылка на каталог и примеры для `@nuxt/icon`, Vue, React и b24-ui. Принимает `i-bx24-outline-check-l`, `bx24:outline-check-l` или `outline-check-l`.

::note
Строковые иконки в пропах компонентов Bitrix24 UI (`<B24Button icon="i-bx24-outline-check-l">`) появятся в версии с [bx-shef/b24-ui#69](https://github.com/bx-shef/b24-ui/issues/69). До неё ассистент найдёт иконку и даст SVG, а в пропы передавайте компонент из `@bitrix24/b24icons-vue`.
::

Каталог для людей — [b24-icons.bx-shef.by](https://b24-icons.bx-shef.by): там тот же поиск, что и у `b24-ui-search-icons`.

## Как ограничить набор инструментов {#limit-available-tools}

Каждый инструмент занимает место в контексте ассистента. Чтобы оставить только нужные, передайте HTTP-заголовок `X-MCP-Tools` со списком имён через запятую:

```json
{
  "X-MCP-Tools": "b24-ui-search-components,b24-ui-get-component,b24-ui-search-icons"
}
```

Без заголовка доступны все инструменты, с пустым заголовком — ни одного. Если в списке есть незнакомое имя, сервер отвечает ошибкой `400` и называет его.

## Ресурсы {#available-resources}

Ресурсы — списки, которые ассистент может прочитать целиком. В Claude Code они подключаются через `@`.

- **`resource://bitrix24-ui/components`** — все компоненты с категориями
- **`resource://bitrix24-ui/composables`** — все композаблы
- **`resource://bitrix24-ui/examples`** — имена всех примеров
- **`resource://bitrix24-ui/documentation-pages`** — все страницы документации

## Промпты {#available-prompts}

Готовые сценарии. В Claude Code они вызываются через `/`.

- **`b24-ui-find-component-for-usecase`** — подобрать компонент под задачу
- **`b24-ui-implement-component-with-props`** — написать готовый код компонента с нужными пропсами

## Подключение {#configuration}

### Claude Code

::note{iconName="InfoCircleIcon"}
**Убедитесь, что Claude Code установлен.** Как его установить, описано в [документации Anthropic](https://docs.anthropic.com/en/docs/claude-code/quickstart).
::

```bash
claude mcp add --transport http b24-ui https://b24-ui.bx-shef.by/mcp/
```

### Claude Desktop

1. Откройте «Settings» > «Developer» и нажмите «Edit Config».
2. Добавьте сервер в `claude_desktop_config.json`:

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "b24-ui": {
      "command": "npx",
      "args": ["mcp-remote", "https://b24-ui.bx-shef.by/mcp/"]
    }
  }
}
```

3. Перезапустите Claude Desktop.

### Cursor

Нажмите кнопку, чтобы установить сервер прямо в Cursor:

::b24-button
---
to: "cursor://anysphere.cursor-deeplink/mcp/install?name=b24-ui&config=eyJ0eXBlIjoiaHR0cCIsInVybCI6Imh0dHBzOi8vYjI0LXVpLmJ4LXNoZWYuYnkvbWNwLyJ9"
label: Установить MCP-сервер
color: air-primary
---
::

Или добавьте его вручную в `.cursor/mcp.json` в корне проекта («Settings» > «Tools & MCP»):

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "b24-ui": {
      "type": "http",
      "url": "https://b24-ui.bx-shef.by/mcp/"
    }
  }
}
```

### Visual Studio Code

::note{iconName="InfoCircleIcon"}
**Нужны расширения** [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) и [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat).
::

Создайте `.vscode/mcp.json` в проекте:

```json [.vscode/mcp.json]
{
  "servers": {
    "b24-ui": {
      "type": "http",
      "url": "https://b24-ui.bx-shef.by/mcp/",
      "headers": {
        "X-MCP-Tools": "b24-ui-search-components,b24-ui-get-component,b24-ui-search-icons,b24-ui-get-icon"
      }
    }
  }
}
```

Уберите `headers`, чтобы получить все инструменты.

### GitHub Copilot CLI

Добавьте сервер в `~/.copilot/mcp-config.json` (или командой `/mcp add` в интерактивном режиме):

```json [~/.copilot/mcp-config.json]
{
  "mcpServers": {
    "b24-ui": {
      "type": "http",
      "url": "https://b24-ui.bx-shef.by/mcp/",
      "tools": ["*"]
    }
  }
}
```

### Gemini CLI

```json [~/.gemini/settings.json]
{
  "mcpServers": {
    "b24-ui": {
      "httpUrl": "https://b24-ui.bx-shef.by/mcp/"
    }
  }
}
```

### Windsurf

«Settings» > «Windsurf Settings» > «Cascade» > «Manage MCPs» > «View raw config»:

```json [.codeium/windsurf/mcp_config.json]
{
  "mcpServers": {
    "b24-ui": {
      "serverUrl": "https://b24-ui.bx-shef.by/mcp/"
    }
  }
}
```

### Zed

```json [.config/zed/settings.json]
{
  "context_servers": {
    "b24-ui": {
      "url": "https://b24-ui.bx-shef.by/mcp/"
    }
  }
}
```

### OpenCode

```json [opencode.json]
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "b24-ui": {
      "type": "remote",
      "url": "https://b24-ui.bx-shef.by/mcp/",
      "enabled": true
    }
  }
}
```

### ChatGPT

Собственные коннекторы MCP доступны в ChatGPT в режиме разработчика («Settings» > «Connectors» > «Advanced settings» > «Developer mode»). Создайте коннектор: имя `Bitrix24 UI`, адрес `https://b24-ui.bx-shef.by/mcp/`, авторизация `None`.

## Примеры запросов {#usage-examples}

После подключения можно спрашивать ассистента так:

- «Какой компонент Bitrix24 UI подойдёт для выбора из списка с поиском?»
- «Покажи пропсы B24Button»
- «Дай пример формы с валидацией»
- «Найди иконку корзины» или «на что заменить CheckLIcon»
- «Дай SVG иконки outline-check-l»
- «Как перейти на эту версию Bitrix24 UI?»

Ассистент сам вызовет нужные инструменты и ответит по актуальной документации.

::tip
Навык [`b24-ui-nuxt`](/docs/getting-started/ai/skills/) и [LLMs.txt](/docs/getting-started/ai/llms-txt/) дополняют MCP: навык даёт ассистенту знания о библиотеке заранее, а MCP — поиск и точные данные по запросу.
::
