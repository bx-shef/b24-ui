## Установка {#installation}

Начните с официального [руководства](https://image.nuxt.com/get-started/installation) или с краткого пересказа:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/image
```

```bash [yarn]
yarn add @nuxt/image
```

```bash [npm]
npm install @nuxt/image
```

```bash [bun]
bun add @nuxt/image
```

::

Затем добавьте модуль `@nuxt/image` в `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    '@bxshefby/b24ui-nuxt',
    '@nuxt/image'
  ],
  css: ['~/assets/css/main.css']
})
```

## Использование {#usage}

Если установлен `@nuxt/image`, Bitrix24 UI отрисовывает компонент [`<NuxtImg>`](https://image.nuxt.com/usage/nuxt-img) вместо нативного тега `img` в компонентах:

- [Avatar](/docs/components/avatar)
- [ColorModeImage](/docs/components/color-mode-image)
- [ProseImg](/docs/typography/images-and-embeds)

Ничего дополнительно настраивать не нужно. Любой пропс `<NuxtImg>`, переданный этим компонентам, например `format`, `quality` или `provider`, пробрасывается в него:

```vue
<template>
  <B24Avatar src="/avatar.png" format="webp" />
</template>
```

::note{to="https://image.nuxt.com/get-started/configuration#domains" target="_blank"}
Удалённые изображения оптимизируются, только если их хост указан в опции `image.domains` файла `nuxt.config.ts`.
::

::tip
Avatar передаёт свой размер как `width` и `height`, поэтому `<NuxtImg>` запрашивает изображение, подходящее под отображаемый размер.
::

### Отключение {#opt-out}

Чтобы отрисовать нативный тег `img` у отдельного Avatar, используйте пропс `as`:

```vue
<template>
  <B24Avatar src="https://example.com/avatar.png" :as="{ img: 'img' }" />
</template>
```
