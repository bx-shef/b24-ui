## Использование {#usage}

Bitrix24 UI добавляет свою конфигурацию к той, которую генерирует [`@nuxt/eslint`](https://eslint.nuxt.com). Она построена на [`eslint-plugin-better-tailwindcss`](https://github.com/schoero/eslint-plugin-better-tailwindcss) и читает вашу таблицу стилей, поэтому знает токены дизайн-системы и ваш `@theme`.

### Настройка {#setup}

Установите плагин рядом с `@nuxt/eslint`:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add -D eslint-plugin-better-tailwindcss
```

```bash [yarn]
yarn add -D eslint-plugin-better-tailwindcss
```

```bash [npm]
npm install -D eslint-plugin-better-tailwindcss
```

```bash [bun]
bun add -D eslint-plugin-better-tailwindcss
```

::

Затем включите конфигурацию опцией `b24ui.eslint` в `nuxt.config.ts`:

```ts [nuxt.config.ts] {4-6}
export default defineNuxtConfig({
  modules: ['@nuxt/eslint', '@bxshefby/b24ui-nuxt'],
  css: ['~/assets/css/main.css'],
  b24ui: {
    eslint: true
  }
})
```

Точкой входа служит таблица стилей из `css`, которая подключает Tailwind CSS.

::note
Если ваш `eslint.config.mjs` уже подключает `eslint-plugin-better-tailwindcss`, конфигурация не добавляется, а предупреждение называет причину. Уберите свою настройку, чтобы использовать эту: два экземпляра плагина вместе ломают ESLint. Если плагин приходит из общей конфигурации, которую вы импортируете, обнаружить его нельзя: оставьте `b24ui.eslint` выключенным.
::

### Правила {#rules}

Классы проверяются в атрибутах `class`, объектах `:b24ui`, в `:b24ui` и `:props` компонента `<B24Theme>` и в `b24ui` файла `app.config.ts`.

| Правило | По умолчанию | Описание |
| --- | --- | --- |
| `no-palette-colors` | `warn` | Классы палитры Tailwind CSS и жёстко заданные цвета. `text-gray-500` подсказывает `text-description`, `bg-red-500` — `bg-alert`, `bg-[#fff]` — семантический токен или проп `color`. |
| `no-conflicting-classes` | `warn` | Классы, задающие одно свойство в одном списке, например `p-2 p-4`. Побеждает не порядок записи, а порядок в таблице стилей. |
| `no-unknown-classes` | `off` | Классы, которые ваша таблица стилей не создаёт. Классы из блока `<style>` или вашего CSS тоже считаются неизвестными, перечислите их в `ignore`. |
| `enforce-logical-properties` | `off` | Физические классы по горизонтальной оси, например `ml-2` или `text-left`, для приложений с поддержкой [RTL](/docs/getting-started/integrations/i18n/nuxt/#dynamic-direction). |

::note
У `no-palette-colors` и `no-conflicting-classes` нет автоисправления: нужный токен или класс зависит от замысла. `enforce-logical-properties` заменяет каждый класс на логический.
::

### Соответствие токенам {#tokens}

Правило `no-palette-colors` подсказывает токен Bitrix24 UI вместо класса палитры Tailwind CSS. Токены сами следуют режиму цветовой схемы (light, dark, edge-light, edge-dark), поэтому вариант `dark:` рядом с ними не нужен.

| Класс палитры | Токен | Что это |
| --- | --- | --- |
| `text-gray-50` … `text-gray-300` | `text-dimmed` | Самый бледный текст |
| `text-gray-400` | `text-muted` | Приглушённый текст |
| `text-gray-500`, `text-gray-600` | `text-description` | Описания и подсказки (рядом `text-legend`) |
| `text-gray-700` … `text-gray-950` | `text-label` | Основной текст и подписи |
| `bg-gray-50` | `bg-elevated` | Приподнятая поверхность |
| `bg-gray-100`, `bg-gray-200` | `bg-muted` | Приглушённый фон |
| `border-gray-50` … `border-gray-300` | `border-default`, `border-muted` | Границы |
| `ring-gray-*`, `divide-gray-*` | `ring-default`, `ring-muted`, `ring-accented`, `divide-default`, `divide-muted`, `divide-accented` | Кольца и разделители |
| `text-red-500`, `bg-rose-500` | `text-alert`, `bg-alert` | Тревога, ошибка |
| `*-orange-*`, `*-amber-*`, `*-yellow-*` | `*-warning` | Предупреждение |
| `*-lime-*`, `*-green-*`, `*-emerald-*` | `*-success` | Успех |
| `*-sky-*`, `*-blue-*` | `*-primary` | Основной цвет |
| `*-indigo-*`, `*-violet-*`, `*-purple-*`, `*-fuchsia-*` | `*-ai` | Цвет AI (Copilot) |

Нейтральные палитры — `slate`, `gray`, `zinc`, `stone`, `neutral`, `taupe`, `mauve`, `mist` и `olive`. Для оттенка нейтральной палитры без подходящего токена (например, `bg-gray-700`) и для цветов без аналога в Bitrix24 UI (`teal`, `cyan`, `pink`) правило перечисляет семантические токены и напоминает про проп `color` компонента.

::note
Фирменные цвета (`alert`, `warning`, `success`, `primary`, `ai`) не зависят от цветовой схемы. Цвет, который должен меняться между light и dark, лучше задать семантическим токеном или пропсом `color` компонента, например `air-primary-alert`.
::

### Конфигурация {#configuration}

Передайте объект в `b24ui.eslint`, чтобы изменить уровень правила или пропустить классы:

```ts [nuxt.config.ts] {4-11}
export default defineNuxtConfig({
  modules: ['@nuxt/eslint', '@bxshefby/b24ui-nuxt'],
  css: ['~/assets/css/main.css'],
  b24ui: {
    eslint: {
      ignore: ['^my-hook$'],
      rules: {
        'no-unknown-classes': 'warn',
        'no-palette-colors': 'error'
      }
    }
  }
})
```

| Опция | Описание |
| --- | --- |
| `entryPoint` | Таблица стилей, которая подключает `tailwindcss` и `@bxshefby/b24ui-nuxt`. По умолчанию берётся найденная в `css`. |
| `files` | Проверяемые файлы. По умолчанию — `.vue` и файлы скриптов. |
| `ignore` | Классы, которые `no-unknown-classes` пропускает, регулярными выражениями. |
| `rules` | Уровень каждого правила: `off`, `warn` или `error`. |
