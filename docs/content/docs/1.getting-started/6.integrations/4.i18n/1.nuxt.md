## Использование {#usage}

::note{to="/docs/components/app/"}
Компонент **App** в Bitrix24 UI оборачивает приложение и задаёт глобальные настройки, в том числе пропс `locale`.
::

### Локаль {#locale}

Передайте в пропс `locale` нужную локаль из `@bitrix24/b24ui-nuxt/locale`:

```vue [app.vue]
<script setup lang="ts">
import { fr } from '@bitrix24/b24ui-nuxt/locale'
</script>

<template>
  <B24App :locale="fr">
    <NuxtPage />
  </B24App>
</template>
```

::tip
У каждой локали есть свойство `code` (например, `en`, `en-GB`, `fr`), которое определяет формат даты и времени в компонентах вроде [Calendar](/docs/components/calendar/), [InputDate](/docs/components/input-date/) и [InputTime](/docs/components/input-time/).
::

### Своя локаль {#custom-locale}

Собственную локаль можно создать утилитой [defineLocale](/docs/composables/define-locale/):

```vue [app.vue]
<script setup lang="ts">
import type { Messages } from '@bitrix24/b24ui-nuxt'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  locale: 'en-AU',
  dir: 'ltr',
  messages: {
    // добавьте пары ключ-значение
  }
})
</script>

<template>
  <B24App :locale="locale">
    <NuxtPage />
  </B24App>
</template>
```

::tip
В параметр `locale` нужно передать ISO-код языка. Например:

* `hi` — хинди (язык)
* `de-AT` — немецкий (язык), как он используется в Австрии (регион)

::

### Расширение локали {#extend-locale}

Существующую локаль можно настроить, переопределив её `messages` утилитой [extendLocale](/docs/composables/extend-locale/):

```vue [app.vue]
<script setup lang="ts">
import { en } from '@bitrix24/b24ui-nuxt/locale'

const locale = extendLocale(en, {
  locale: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <B24App :locale="locale">
    <NuxtPage />
  </B24App>
</template>
```

### Динамическая локаль {#dynamic-locale}

Для динамического переключения языков можно использовать модуль [Nuxt I18n](https://i18n.nuxtjs.org/).

::steps{level="4"}

#### Установите пакет Nuxt I18n {#install-the-nuxt-i18n-package}

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxtjs/i18n
```

```bash [yarn]
yarn add @nuxtjs/i18n
```

```bash [npm]
npm install @nuxtjs/i18n
```

```bash [bun]
bun add @nuxtjs/i18n
```

::

#### Добавьте модуль Nuxt I18n в `nuxt.config.ts`{lang="ts-type"} {#add-the-nuxt-i18n-module-in-your-nuxtconfigts}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@bitrix24/b24ui-nuxt',
    '@nuxtjs/i18n'
  ],
  css: ['~/assets/css/main.css'],
  i18n: {
    locales: [
      {
        code: 'de',
        name: 'Deutsch'
      },
      {
        code: 'en',
        name: 'English'
      },
      {
        code: 'fr',
        name: 'Français'
      }
    ]
  }
})
```

#### Автоматическая локаль :badge{label="2.15+" class="align-text-top"} {#automatic-locale}

Если установлен `@nuxtjs/i18n`, компонент `App` следует текущей локали i18n. Подключаются только локали Bitrix24 UI, совпадающие с вашими `i18n.locales`, и каждая загружается, когда приложение переключается на неё:

```vue [app.vue]
<template>
  <B24App>
    <NuxtPage />
  </B24App>
</template>
```

::tip
Локаль подбирается по языковому тегу из `language` или `code`; если точного совпадения нет, берётся базовый язык (например, для `pt-BR` используется `br`, а для `en-US` — `en`). Короткие имена экспорта Bitrix24 UI (`br`, `kz`, `la`, `ua`, …) не являются языковыми тегами, поэтому, если ваш `code` не тег, задайте `language`. Локаль без совпадения заменяется английской. Чтобы переопределить выбор, передайте пропс `locale`, например со [своей локалью](#custom-locale).
::

#### Автоматическая локализация ссылок {#automatic-link-localization}

Если установлен `@nuxtjs/i18n`, компонент [Link](/docs/components/link/) сам локализует внутренние ссылки через помощник `$localePath`. Оборачивать ссылки в `localePath()` или `localeRoute()` вручную не нужно.

```vue
<template>
  <!-- Автоматически превращается в /en/about или /fr/about в зависимости от текущей локали -->
  <B24Link to="/about">About</B24Link>
  <B24Button to="/contact">Contact</B24Button>
</template>
```

::tip
Внешние ссылки и абсолютные URL определяются автоматически и не локализуются. При необходимости `localePath()` и `localeRoute()` по-прежнему можно использовать вручную.
::

::

### Динамическое направление {#dynamic-direction}

У каждой локали есть свойство `dir`: компонент `App` использует его, чтобы задать направление текста всем компонентам.

::note
Внутри компонента файлы локалей почти не нужны: композабл `useLocale` читает локаль, которую уже предоставляет `<B24App>`: `const { t, lang, code, dir, locale } = useLocale()`{lang="ts"}. `t()`{lang="ts"} переводит по активным сообщениям, а `dir` нужен, когда ваш собственный компонент должен следовать направлению текста.
::

В многоязычном приложении атрибуты `lang` и `dir` элемента `<html>` можно менять динамически по локали пользователя — для этого есть композабл [useLocaleHead](https://i18n.nuxtjs.org/docs/composables/use-locale-head). Он читает `language` и `dir` из ваших `i18n.locales`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  i18n: {
    locales: [{
      code: 'ar',
      language: 'ar',
      dir: 'rtl',
      name: 'العربية'
    }, {
      code: 'en',
      language: 'en',
      name: 'English'
    }]
  }
})
```

```vue [app.vue]
<script setup lang="ts">
const head = useLocaleHead()

useHead(() => ({
  htmlAttrs: head.value.htmlAttrs
}))
</script>

<template>
  <B24App>
    <NuxtPage />
  </B24App>
</template>
```

::note
При включённой опции `experimental.strictSeo` эти атрибуты задаёт сам `@nuxtjs/i18n`, а `useLocaleHead` вызывать нельзя.
::
