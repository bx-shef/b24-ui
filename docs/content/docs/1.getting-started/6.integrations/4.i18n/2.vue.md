## Использование {#usage}

::note{to="/docs/components/app/"}
Компонент **App** в Bitrix24 UI оборачивает приложение и задаёт глобальные настройки, в том числе пропс `locale`.
::

### Локаль {#locale}

Передайте в пропс `locale` нужную локаль из `@bitrix24/b24ui-nuxt/locale`:

```vue [App.vue]
<script setup lang="ts">
import { fr } from '@bitrix24/b24ui-nuxt/locale'
</script>

<template>
  <B24App :locale="fr">
    <RouterView />
  </B24App>
</template>
```

::tip
У каждой локали есть свойство `code` (например, `en`, `en-GB`, `fr`), которое определяет формат даты и времени в компонентах вроде [Calendar](/docs/components/calendar/), [InputDate](/docs/components/input-date/) и [InputTime](/docs/components/input-time/).
::

### Своя локаль {#custom-locale}

Собственную локаль можно создать утилитой [defineLocale](/docs/composables/define-locale/):

```vue [App.vue]
<script setup lang="ts">
import type { Messages } from '@bitrix24/b24ui-nuxt'
import { defineLocale } from '@bitrix24/b24ui-nuxt/composables'

const locale = defineLocale<Messages>({
  name: 'My custom locale',
  code: 'en',
  locale: 'en-AU',
  dir: 'ltr',
  messages: {
    // добавьте пары ключ-значение
  }
})
</script>

<template>
  <B24App :locale="locale">
    <RouterView />
  </B24App>
</template>
```

::tip
В параметр `locale` нужно передать ISO-код языка. Например:

* `hi` — хинди (язык)
* `de-AT` — немецкий (язык), как он используется в Австрии (регион)

::

### Расширение локали {#extend-locale}

Существующую локаль можно настроить, переопределив её `messages` утилитой [extendLocale](/docs/composables/extend-locale/):

```vue [App.vue]
<script setup lang="ts">
import { en } from '@bitrix24/b24ui-nuxt/locale'
import { extendLocale } from '@bitrix24/b24ui-nuxt/composables/'

const locale = extendLocale(en, {
  locale: 'en-AU',
  messages: {
    commandPalette: {
      placeholder: 'Search a component...'
    }
  }
})
</script>

<template>
  <B24App :locale="locale">
    <RouterView />
  </B24App>
</template>
```

### Динамическая локаль {#dynamic-locale}

Для динамического переключения языков можно использовать плагин [Vue I18n](https://vue-i18n.intlify.dev/).

::steps{level="4"}

#### Установите пакет Vue I18n {#install-the-vue-i18n-package}

::code-group{sync="pm"}

```bash [pnpm]
pnpm add vue-i18n@11
```

```bash [yarn]
yarn add vue-i18n@11
```

```bash [npm]
npm install vue-i18n@11
```

```bash [bun]
bun add vue-i18n@11
```

::

#### Подключите плагин Vue I18n в `main.ts` {#use-the-vue-i18n-plugin-in-your-maints}

```ts [src/main.ts]{3,14-26,29}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from 'vue-i18n'
import b24UiPlugin from '@bitrix24/b24ui-nuxt/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  availableLocales: ['en', 'de'],
  messages: {
    en: {
      // ...
    },
    de: {
      // ...
    }
  }
})

app.use(router)
app.use(i18n)
app.use(b24UiPlugin)

app.mount('#app')
```

#### Задайте пропс `locale` через `useI18n` {#set-the-locale-prop-using-usei18n}

Импортируйте только те локали, которые поддерживает приложение, — остальные в сборку не попадут:

```vue [App.vue]
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import { de, en } from '@bitrix24/b24ui-nuxt/locale'

const locales = { de, en }

const { locale } = useI18n()
</script>

<template>
  <B24App :locale="locales[locale]">
    <RouterView />
  </B24App>
</template>
```

::

### Динамическое направление {#dynamic-direction}

У каждой локали есть свойство `dir`: компонент `App` использует его, чтобы задать направление текста всем компонентам.

::note
Внутри компонента файлы локалей почти не нужны: композабл `useLocale` читает локаль, которую уже предоставляет `<B24App>`: `const { t, lang, code, dir, locale } = useLocale()`{lang="ts"}. `t()`{lang="ts"} переводит по активным сообщениям, а `dir` нужен, когда ваш собственный компонент должен следовать направлению текста.
::

В многоязычном приложении атрибуты `lang` и `dir` элемента `<html>` можно менять динамически по локали пользователя — для этого есть композабл [useHead](https://unhead.unjs.io/docs/head/api/composables/use-head):

```vue [App.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { useHead } from '@unhead/vue'
import { de, en } from '@bitrix24/b24ui-nuxt/locale'

const locales = { de, en }

const { locale } = useI18n()

const lang = computed(() => locales[locale.value].locale)
const dir = computed(() => locales[locale.value].dir)

useHead({
  htmlAttrs: {
    lang,
    dir
  }
})
</script>

<template>
  <B24App :locale="locales[locale]">
    <RouterView />
  </B24App>
</template>
```
