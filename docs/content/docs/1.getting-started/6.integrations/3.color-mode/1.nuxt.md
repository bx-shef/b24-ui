## Обзор {#overview}

Bitrix24 UI предоставляет гибкую систему цветовых схем на основе [VueUse](https://vueuse.org/core/useColorMode/). Поддерживаются пять режимов:

- **light** – классическая светлая тема (по умолчанию)
- **dark** – классическая тёмная тема
- **edge-light** – светлая тема со светлым фоном и настраиваемым фоновым изображением
- **edge-dark** – светлая тема с тёмным фоном и настраиваемым фоновым изображением
- **auto** – следует настройке операционной системы пользователя (переключается между `light` и `dark` по `prefers-color-scheme`)

Кроме того, в режиме `auto` применяется CSS-класс **base-mode**. Он сопоставляет `edge-light` и `edge-dark` с `light` или `dark` в зависимости от настройки системы и сохраняет их переменные фона.

Система учитывает и платформу (мобильную, настольную, веб): если у элемента `<html>` есть соответствующий атрибут `data-platform`, для неё загружаются отдельные дизайн-токены.

## Использование {#usage}

Bitrix24 UI сам регистрирует композабл VueUse, поэтому дополнительная настройка не нужна.

### Компоненты {#components}

Встроенные компоненты [ColorModeAvatar](/docs/components/color-mode-avatar/) и [ColorModeImage](/docs/components/color-mode-image/) показывают разные изображения для каждой цветовой схемы. Компоненты [ColorModeButton](/docs/components/color-mode-button/), [ColorModeSwitch](/docs/components/color-mode-switch/) и [ColorModeSelect](/docs/components/color-mode-select/) позволяют пользователю переключаться между всеми доступными режимами (light, dark, edge-light, edge-dark, auto).

Чтобы создать собственный компонент управления цветовой схемой, используйте композабл Bitrix24 UI [useColorMode](https://github.com/bitrix24/b24ui/blob/main/src/runtime/composables/color-mode/useColorMode.ts).

```vue [ColorModeButton.vue]
<script setup lang="ts">
import { useColorMode } from '@bitrix24/b24ui-nuxt/composables'
import SunIconAir from '@bitrix24/b24icons-vue/outline/SunIcon'
import MoonIconAir from '@bitrix24/b24icons-vue/outline/MoonIcon'

const colorMode = useColorMode()

const isDark = computed({
  get() {
    return colorMode.value === 'dark'
  },
  set(_isDark: boolean) {
    colorMode.preference = _isDark ? 'dark' : 'light'
  }
})
</script>

<template>
  <B24Button
    :icon="isDark ? MoonIconAir : SunIconAir"
    :aria-label="`Switch to ${isDark ? 'light' : 'dark'} mode`"
    @click="isDark = !isDark"
  />
</template>
```

### Настройка {#configuration}

Поведение цветовой схемы настраивается опциями модуля `b24ui` в `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@bitrix24/b24ui-nuxt'],
  css: ['~/assets/css/main.css'],
  b24ui: {
    // Полностью включить или отключить плагин цветовой схемы
    colorMode: true,
    // Начальная схема, если сохранённой настройки нет
    colorModeInitialValue: 'light',               // 'auto' | 'dark' | 'light' | 'edge-dark' | 'edge-light'
    // Какой режим считать «светлым»
    colorModeTypeLight: 'light',                  // 'light' | 'edge-dark' | 'edge-light'
    // Ключ хранилища для настройки пользователя (null отключает сохранение)
    colorModeStorageKey: 'vueuse-color-scheme'    // string | null
  }
})
```

#### Описание опций {#options-explained}

- **`colorMode`** (`boolean`, по умолчанию `true`)  
  Включает или отключает интеграцию цветовой схемы. Если она отключена, `useColorMode()` возвращает объект-заглушку с `forced: true`.

- **`colorModeInitialValue`** (`'auto' | 'dark' | 'light' | 'edge-dark' | 'edge-light'`, по умолчанию `'light'`)  
  Режим, который используется, пока пользователь не выбрал схему (в localStorage/sessionStorage нет сохранённого значения).  
  Если задать `colorModeTypeLight` и `colorModeInitialValue` равными `'edge-dark'`, сайт откроется в теме edge-dark.

- **`colorModeTypeLight`** (`'light' | 'edge-dark' | 'edge-light'`, по умолчанию `'light'`)  
  Определяет, какой режим считается «светлым». Это влияет на переключатель `light`/`dark`: когда пользователь выбирает «светлую» схему, включается режим, указанный здесь.  
  Пример: при `colorModeTypeLight: 'edge-dark'` настройка `light` соответствует теме `edge-dark`.

- **`colorModeStorageKey`** (`string | null`, по умолчанию `'vueuse-color-scheme'`)  
  Ключ, под которым настройка пользователя хранится в localStorage/sessionStorage. Значение `null` отключает сохранение (выбор пропадёт после перезагрузки страницы).

Все эти опции доступны и в `app.config.ts` приложения (они объединяются с опциями модуля).

### Свои фоновые изображения {#customizing-background-images}

Режимы `edge-light` и `edge-dark` рассчитаны на собственные фоновые изображения. Переменные фона по умолчанию переопределяются CSS-правилами в файле `main.css`.

#### Пример: фон для `edge-dark` {#example-setting-a-background-for-edge-dark}

```css [assets/css/main.css]
@layer base {
  .edge-dark {
    --air-theme-bg-image: url(/bg/edge-dark-v4.jpeg);
    --air-theme-bg-position: 0 0;
    --air-theme-bg-size: cover;
    --air-theme-bg-repeat: no-repeat;
    --air-theme-bg-attachment: fixed;
    --air-theme-bg-color: #162345;
  }
}
```

#### Пример: фон для `edge-light` {#example-setting-a-background-for-edge-light}

```css [assets/css/main.css]
@layer base {
  .edge-light {
    --air-theme-bg-image: url(/bg/edge-light-v1.svg);
    --air-theme-bg-position: 0 0;
    --air-theme-bg-size: 240px 240px;
    --air-theme-bg-repeat: repeat;
    --air-theme-bg-attachment: fixed;
    --air-theme-bg-color: #f1dbdb87;
  }
}
```

Те же переменные можно переопределить для отдельного компонента через произвольные варианты Tailwind:

```vue [SlideoverSimpleListElementsExample.vue]
<B24Slideover
  :b24ui="{
    content: [
      'air-custom-bg',
      'edge-dark',
      'edge-dark:[--air-theme-bg-color:#7c235b]',
      'edge-dark:[--air-theme-bg-size:cover]',
      'edge-dark:[--air-theme-bg-image:url(/bg/edge-dark-v2.jpg)]'
    ].join(' ')
  }"
>
  <!-- ... -->
</B24Slideover>
```

### Токены для платформ {#platform-specific-tokens}

Если приложение работает внутри мобильного или настольного приложения Bitrix24, элемент `<html>` получает атрибут `data-platform="bitrix-mobile"` или `data-platform="bitrix-desktop"`. Для этих платформ автоматически загружаются отдельные файлы дизайн-токенов (`*_mobile_*.css`, `*_desktop_*.css`), которые подстраивают цветовую палитру под среду.
