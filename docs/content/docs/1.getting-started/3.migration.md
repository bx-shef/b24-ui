Руководство по шагам показывает, как перевести приложение на Bitrix24 UI v2.

## Изменения {#changes}

После перехода на Bitrix24 UI v2 учтите следующие важные изменения:

### ButtonGroup переименован {#renamed-buttongroup}

Компонент `ButtonGroup` переименован в [`FieldGroup`](/docs/components/field-group/):

```diff
<template>
- <B24ButtonGroup>
+ <B24FieldGroup>
    <B24Button label="Button" />
    <B24Button use-dropdown />
+ </B24FieldGroup>
- </B24ButtonGroup>
</template>
```

### Модификаторы модели переименованы {#renamed-model-modifiers}

В v2 изменилась форма `modelModifiers` у [`Input`](/docs/components/input/), [`InputNumber`](/docs/components/input-number/) и [`Textarea`](/docs/components/textarea/):

1. Модификатор `nullify` переименован в `nullable` (он превращает пустые значения в `null`).
2. Добавлен модификатор `optional` (он превращает пустые значения в `undefined`).

```diff
- <B24Input v-model.nullify="value" />
+ <B24Input v-model.nullable="value" />
```

```diff
- <B24Textarea v-model="value" :model-modifiers="{ nullify: true }" />
+ <B24Textarea v-model="value" :model-modifiers="{ nullable: true }" />
```

`nullable` подойдёт, если пустое значение должно быть `null`, а `optional` — если отсутствующее значение лучше представлять как `undefined`.

### Изменения в компоненте Form {#changes-to-form-component}

В v2 компонент `Form` получил улучшенное управление состоянием и работу с вложенными формами. Главные изменения:

1. Преобразования схемы **применяются только к данным события `@submit`** и не меняют состояние формы. Так поведение предсказуемее, а состояние не изменяется неожиданно.
2. **Вложенные формы включаются явно** пропсом `nested`. Поведение компонента становится очевиднее, и вложенная форма не появится случайно.
3. **У вложенных форм нужно задавать пропс `name`** (как у `B24FormField`); состояние они автоматически наследуют от родительской формы.

```diff
<template>
  <B24Form :state="state" :schema="schema" @submit="onSubmit">
    <B24FormField label="Customer" name="customer">
      <B24Input v-model="state.customer" placeholder="Wonka Industries" />
    </B24FormField>

    <div v-for="(item, index) in state.items" :key="index">
      <B24Form
-       :state="item"
+       :name="`items.${index}`"
        :schema="itemSchema"
+       nested
      >
        <B24FormField :label="!index ? 'Description' : undefined" name="description">
          <B24Input v-model="item.description" />
        </B24FormField>
        <B24FormField :label="!index ? 'Price' : undefined" name="price">
          <B24Input v-model="item.price" type="number" />
        </B24FormField>
      </B24Form>
    </div>
  </B24Form>
</template>
```

### useSidebarLayout удалён {#usesidebarlayout-removed}

Композабл `useSidebarLayout` не поддерживается.

Поддержка состояния загрузки компонента [SidebarLayout](/docs/components/sidebar-layout/) через [DashboardGroup](/docs/components/dashboard-group/) появится в одном из ближайших выпусков.

### @bitrix24/b24style удалён {#bitrix24b24style-removed}

Оформлением занимаются стили [Bitrix24 UI](https://github.com/bitrix24/b24ui/tree/main/src/runtime/air-design-tokens).

Мы старались сохранить совместимость, но если возникнут проблемы, [сообщите нам](https://github.com/bitrix24/b24ui/issues).
