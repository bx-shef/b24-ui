Bitrix24 UI из этого репозитория публикуется в npm как `@bxshefby/b24ui-nuxt`, начиная с версии 2.16.0. Версии продолжают линию `@bitrix24/b24ui-nuxt`: 2.16.0 идёт следом за 2.15.0, компоненты, параметры модуля и ключ настроек `b24ui` те же.

Пакеты иконок `@bitrix24/b24icons-vue` и другие `@bitrix24/b24icons-*` остаются под своими именами — их менять не нужно.

Перейти можно двумя путями.

## Псевдоним без правки кода {#alias}

Пакет ставится под прежним именем, а скачивается `@bxshefby/b24ui-nuxt`. Импорты, `modules` в `nuxt.config.ts` и `@import` в CSS остаются как есть.

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @bitrix24/b24ui-nuxt@npm:@bxshefby/b24ui-nuxt@^2.16.0
```

```bash [yarn]
yarn add @bitrix24/b24ui-nuxt@npm:@bxshefby/b24ui-nuxt@^2.16.0
```

```bash [npm]
npm install @bitrix24/b24ui-nuxt@npm:@bxshefby/b24ui-nuxt@^2.16.0
```

```bash [bun]
bun add @bitrix24/b24ui-nuxt@npm:@bxshefby/b24ui-nuxt@^2.16.0
```

::

В `package.json` получится запись:

```json [package.json]
{
  "dependencies": {
    "@bitrix24/b24ui-nuxt": "npm:@bxshefby/b24ui-nuxt@^2.16.0"
  }
}
```

Этот путь удобен, когда приложений много или имя пакета встречается в общем коде, который правится не сразу.

## Замена имени {#rename}

Имя пакета меняется во всех местах, где оно встречается.

::steps{level="3"}

### Замените зависимость {#replace-the-dependency}

::code-group{sync="pm"}

```bash [pnpm]
pnpm remove @bitrix24/b24ui-nuxt
pnpm add @bxshefby/b24ui-nuxt
```

```bash [yarn]
yarn remove @bitrix24/b24ui-nuxt
yarn add @bxshefby/b24ui-nuxt
```

```bash [npm]
npm uninstall @bitrix24/b24ui-nuxt
npm install @bxshefby/b24ui-nuxt
```

```bash [bun]
bun remove @bitrix24/b24ui-nuxt
bun add @bxshefby/b24ui-nuxt
```

::

### Замените модуль в `nuxt.config.ts` {#replace-the-module}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
- modules: ['@bitrix24/b24ui-nuxt'],
+ modules: ['@bxshefby/b24ui-nuxt'],
  css: ['~/assets/css/main.css']
})
```

Ключ настроек модуля — `b24ui`, как и у `@bitrix24/b24ui-nuxt`.

### Замените импорт в CSS {#replace-the-css-import}

```diff [app/assets/css/main.css]
@import "tailwindcss";
- @import "@bitrix24/b24ui-nuxt";
+ @import "@bxshefby/b24ui-nuxt";
```

### Замените импорты в коде {#replace-the-imports}

Типы, композаблы, локали и подпути пакета импортируются из `@bxshefby/b24ui-nuxt`:

```diff
- import type { TableColumn } from '@bitrix24/b24ui-nuxt'
- import { ru } from '@bitrix24/b24ui-nuxt/locale'
+ import type { TableColumn } from '@bxshefby/b24ui-nuxt'
+ import { ru } from '@bxshefby/b24ui-nuxt/locale'
```

В приложении на Vue так же меняются `@bitrix24/b24ui-nuxt/vite` и `@bitrix24/b24ui-nuxt/vue-plugin`. Псевдонимы `#b24ui` и `#build/b24ui` остаются без изменений.

::

::tip
Найти все вхождения прежнего имени в проекте можно командой `grep -rn "@bitrix24/b24ui-nuxt" --exclude-dir=node_modules .`
::
