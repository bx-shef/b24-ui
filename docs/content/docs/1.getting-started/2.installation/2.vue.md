## Настройка {#setup}

### Шаблон для Vue {#use-a-vue-template}

Начните с одного из [официальных шаблонов](/templates/): кнопка `Use this template` на GitHub или командная строка:

::code-group{sync="pm-v"}

```bash [Dashboard]
git clone https://github.com/bitrix24/templates-dashboard-vue.git <project-name>
cd <project-name>
pnpm install
pnpm run dev
```

```bash [Starter]
git clone https://github.com/bitrix24/starter-b24ui-vue.git <project-name>
cd <project-name>
pnpm install
pnpm run dev
```

::

::note
Аргумент `<project-name>` — имя каталога, в котором будет создан проект. Замените его названием вашего проекта.

### Добавление в проект на Vue {#add-to-a-vue-project}

::steps{level="4"}

#### Установите пакет Bitrix24 UI {#install-the-bitrix24-ui-package}

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @bxshefby/b24ui-nuxt @bitrix24/b24icons-vue tailwindcss
```

```bash [yarn]
yarn add @bxshefby/b24ui-nuxt @bitrix24/b24icons-vue tailwindcss
```

```bash [npm]
npm install @bxshefby/b24ui-nuxt @bitrix24/b24icons-vue tailwindcss
```

```bash [bun]
bun add @bxshefby/b24ui-nuxt @bitrix24/b24icons-vue tailwindcss
```

::

::note{to="/docs/getting-started/package/"}
Приложение на пакете из npm-организации `@bitrix24` переводится на `@bxshefby/b24ui-nuxt` псевдонимом в `package.json` или заменой имени.

#### Добавьте плагин Bitrix24 UI для Vite в `vite.config.ts`{lang="ts-type"} {#add-the-bitrix24-ui-vite-plugin-in-your-viteconfigts}

::code-group{sync="vite"}

```ts [vite.config.ts (Vite)]{3,8}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite()
  ]
})
```

```ts [vite.config.ts (Laravel Inertia)]{3,20-22}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'
import laravel from 'laravel-vite-plugin'

export default defineConfig({
  plugins: [
    laravel({
      input: ['resources/js/app.ts'],
      refresh: true
    }),
    vue({
      template: {
        transformAssetUrls: {
          base: null,
          includeAbsolute: false
        }
      }
    }),
    bitrix24UIPluginVite({
      router: 'inertia'
    })
  ]
})
```

```ts [vite.config.ts (AdonisJS Inertia)]{3,15-17}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'
import adonisjs from '@adonisjs/vite/client'
import inertia from '@adonisjs/inertia/client'

export default defineConfig({
  plugins: [
    adonisjs({
      entrypoints: ['inertia/app/app.ts'],
      reload: ['resources/views/**/*.edge']
    }),
    inertia(),
    vue(),
    bitrix24UIPluginVite({
      router: 'inertia'
    })
  ]
})
```

::

::tip
Bitrix24 UI регистрирует `unplugin-auto-import` и `unplugin-vue-components`, которые создают файлы деклараций типов `auto-imports.d.ts` и `components.d.ts`. Скорее всего, их стоит добавить в `.gitignore` и в `tsconfig`.

```json [tsconfig.app.json]
{
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue", "auto-imports.d.ts", "components.d.ts"]
}
```

```bash [.gitignore]
# Автоматически созданные декларации типов
auto-imports.d.ts
components.d.ts
```

::

::warning
Файлы деклараций записываются только при работе Vite. Скрипт `build` из шаблона `create-vue` запускает `vue-tsc` параллельно с `vite build` (`run-p type-check "build-only {@}"`), поэтому в чистой копии проверка типов может начаться раньше, чем файлы появятся, и завершиться ошибкой вроде `Cannot find name 'useToast'`. Запускайте проверку типов после сборки, чтобы декларации успели создаться.

```json [package.json]
{
  "scripts": {
    "build": "run-s build-only type-check"
  }
}
```

::

::tip
Внутри Bitrix24 UI использует собственный алиас для разрешения типов темы. Если вы пишете на TypeScript, добавьте алиас в `tsconfig`, чтобы в `vite.config.ts` работало автодополнение.

```json [tsconfig.node.json]
{
  "compilerOptions": {
    "paths": {
      "#build/b24ui": [
        "./node_modules/.b24ui-nuxt/b24ui"
      ]
    }
  }
}
```

```json [tsconfig.app.json]
{
  "compilerOptions": {
    "paths": {
      "#build/b24ui/*": [
        "./node_modules/.b24ui-nuxt/b24ui/*"
      ]
    }
  }
}
```
::

#### Подключите Vue-плагин Bitrix24 UI {#use-the-bitrix24-ui-vue-plugin}

::code-group{sync="vite"}

```ts [src/main.ts (Vite)]{3,14}
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import b24UiPlugin from '@bxshefby/b24ui-nuxt/vue-plugin'
import App from './App.vue'

const app = createApp(App)

const router = createRouter({
  routes: [],
  history: createWebHistory()
})

app.use(router)
app.use(b24UiPlugin)

app.mount('#app')
```

```ts [resources/js/app.ts (Laravel Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import b24UiPlugin from '@bxshefby/b24ui-nuxt/vue-plugin'
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers'
import { createApp, h } from 'vue'

const appName = import.meta.env.VITE_APP_NAME || 'Laravel x Bitrix24 UI'

createInertiaApp({
  title: title => (title ? `${title} - ${appName}` : appName),
  resolve: name =>
    resolvePageComponent(
      `./pages/${name}.vue`,
      import.meta.glob<DefineComponent>('./pages/**/*.vue')
    ),
  setup({ el, App, props, plugin }) {
    createApp({ render: () => h(App, props) })
      .use(plugin)
      .use(b24UiPlugin)
      .mount(el)
  }
})
```

```ts [inertia/app/app.ts (AdonisJS Inertia)]{3,19}
import type { DefineComponent } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'
import b24UiPlugin from '@bxshefby/b24ui-nuxt/vue-plugin'
```

## Опции {#options}

Bitrix24 UI настраивается опциями в `vite.config.ts`.

### `colorMode`

Опция `colorMode` включает или отключает интеграцию цветовой схемы из `@vueuse/core`.

- По умолчанию: `true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      colorMode: false
    })
  ]
})
```

### `theme.unstyled`

Опция `theme.unstyled` убирает из компонентов все классы темы по умолчанию. Остаются только их структура и классы, которые вы передаёте через `class`, `b24ui` или `app.config.b24ui`.

- По умолчанию: `false`{lang="ts-type"}

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      theme: {
        unstyled: true
      }
    })
  ]
})
```

::warning
Вместе с оформлением убираются и **структурные** классы (позиционирование, переходы, flex/grid). У компонентов со сложной раскладкой, таких как `Modal`, `Drawer` или `Calendar`, раскладку придётся задать самостоятельно — как в unstyled-режиме PrimeVue.
::

### `theme.prefix`

Опция `theme.prefix` задаёт тот же префикс, что и в импорте Tailwind CSS. Так компоненты Bitrix24 UI используют правильные утилитарные классы и CSS-переменные с префиксом.

::code-group

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      theme: {
        prefix: 'tw'
      }
    })
  ]
})
```

```css [src/assets/css/main.css] {1}
@import "tailwindcss" prefix(tw);
@import "@bxshefby/b24ui-nuxt";
```

::

Префикс автоматически добавляется ко всем утилитарным классам Tailwind и CSS-переменным в темах компонентов Bitrix24 UI:

```html
<!-- Без префикса -->
<button class="px-2 py-1 text-xs hover:bg-red-500/75">Button</button>

<!-- С префиксом tw -->
<button class="tw:px-2 tw:py-1 tw:text-xs tw:hover:bg-red-500/75">Button</button>
```

::note{to="https://tailwindcss.com/docs/styling-with-utility-classes#using-the-prefix-option" target="_blank"}
Подробнее о префиксе — в документации Tailwind CSS.
::

### `prose`

Опция `prose` включает компоненты `<Prose>` из Bitrix24 UI и их тему.

- По умолчанию: `true`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      prose: false
    })
  ]
})
```

### `autoImport`

Опция `autoImport` отключает автоимпорт композаблов или настраивает параметры [`unplugin-auto-import`](https://github.com/unplugin/unplugin-auto-import).

- По умолчанию: `{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      autoImport: false
    })
  ]
})
```

::note
Если автоимпорт отключён, композаблы всё равно можно импортировать явно из `@bxshefby/b24ui-nuxt/composables`.
::

### `components`

Опция `components` отключает автоимпорт компонентов или настраивает параметры [`unplugin-vue-components`](https://github.com/unplugin/unplugin-vue-components).

- По умолчанию: `{}`{lang="ts-type"}

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      components: false
    })
  ]
})
```

::note
Если автоимпорт отключён, компоненты всё равно можно импортировать явно, например `import Button from '@bxshefby/b24ui-nuxt/components/Button.vue'` or `import ProseCode from '@bxshefby/b24ui-nuxt/components/prose/Code.vue'`.
::

### `router`

Опция `router` настраивает интеграцию с маршрутизацией. Она нужна приложениям без `vue-router`: Electron-приложениям, MPA и фреймворкам вроде [Inertia.js](https://inertiajs.com/) или [Hybridly](https://hybridly.dev/).

- По умолчанию: `true`{lang="ts-type"}

| Значение | Описание |
| -------- | -------- |
| `true`{lang="ts-type"} | Навигация через `vue-router` с компонентом `RouterLink`. |
| `false`{lang="ts-type"} | Интеграция с маршрутизацией отключена, ссылки отрисовываются обычными тегами `<a>`. |
| `'inertia'`{lang="ts-type"} | Навигация через Inertia.js с её компонентом `Link`. |

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      router: false
    })
  ]
})
```

::tip
Собственную логику навигации для фреймворков вроде **Hybridly** можно задать так: установите `router: false` в конфигурации Vite и передайте функцию при подключении Vue-плагина:

```ts [src/main.ts]
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'
import { router } from 'hybridly'

app.use(bitrix24UIPluginVite, {
  router: (event, { href, external }) => {
    if (external) {
      return
    }

    event.preventDefault()

    router.navigate({ url: href })
  }
})
```
::

::note
При значении `false` или `'inertia'` `vue-router` как зависимость не нужен.
::

### `scanPackages`

Опция `scanPackages` задаёт дополнительные npm-пакеты, в которых нужно искать компоненты Bitrix24 UI. Она полезна, если у вас есть общая библиотека компонентов, использующая компоненты Bitrix24 UI внутри.

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      scanPackages: ['@my-org/b24ui-components']
    })
  ]
})
```

::note
По умолчанию сканируется только `@bxshefby/b24ui-nuxt`. Используйте опцию, если во внешних пакетах есть Vue-компоненты, которые используют Bitrix24 UI.
::

### `root`

Опция `root` переопределяет каталог, в котором Bitrix24 UI создаёт каталог `.b24ui-nuxt` (шаблоны темы). По умолчанию берётся `root` из Vite, но в таких сборках, как [`electron-vite`](https://electron-vite.org/), `root` рендерера указывает на подкаталог (например, `src/renderer`). Тогда шаблоны попадают в `src/renderer/node_modules/.b24ui-nuxt`, куда Tailwind не заглядывает, и классы темы пропадают.

```ts [electron.vite.config.ts] {12}
import { defineConfig } from 'electron-vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  renderer: {
    root: 'src/renderer',
    plugins: [
      vue(),
      bitrix24UIPluginVite({
        root: __dirname
      })
    ]
  }
})
```

::note
Укажите в `root` корень проекта, чтобы созданный каталог `.b24ui-nuxt` оказался в `node_modules`, который сканирует Tailwind.
::

### `experimental.componentDetection` :badge{label="2.12+" class="align-text-top"}

Опция `experimental.componentDetection` включает автоматическое определение компонентов для tree-shaking. Исходный код сканируется, находятся реально используемые компоненты, и CSS генерируется только для них (вместе с их зависимостями). Без опции плагин Vite генерирует CSS темы для каждого компонента. Определение охватывает корень Vite, пакеты из [`scanPackages`](#scanpackages) и все `dirs` из опции [`components`](#components), лежащие вне корня.

- По умолчанию: `false`{lang="ts-type"}
- Тип: `boolean | string[]`{lang="ts-type"}

**Включить автоматическое определение:**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      experimental: {
        componentDetection: true
      }
    })
  ]
})
```

**Добавить компоненты для динамического использования:**

```ts [vite.config.ts] {9-11}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      experimental: {
        componentDetection: ['Modal', 'DropdownMenu', 'Popover']
      }
    })
  ]
})
```

::note
Если передать массив имён компонентов, автоматическое определение включается, а перечисленные компоненты (вместе с зависимостями) гарантированно попадают в сборку. Это удобно для динамических компонентов вроде `<component :is="..." />`, которые нельзя проанализировать статически. Имя, не принадлежащее компоненту, приводит к предупреждению, а не игнорируется молча.
::

::warning
Новые используемые компоненты подхватываются при следующем запуске сервера разработки. Если вы добавили компонент, а его стилей нет, перезапустите сервер.
::
