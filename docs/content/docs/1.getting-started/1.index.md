## Что такое Bitrix24 UI? {#what-is-bitrix24-ui}

Библиотека Vue-компонентов для Bitrix24 на основе [Nuxt UI](https://ui.nuxt.com). Она построена на [Reka UI](https://reka-ui.com/), [Tailwind CSS](https://tailwindcss.com/) и [Tailwind Variants](https://www.tailwind-variants.org/) и позволяет создавать красивые и доступные приложения из более чем 100 готовых компонентов.

Если вы делаете Vue-проект с Tailwind CSS, Bitrix24 UI — хороший выбор по умолчанию. Библиотека даёт готовые компоненты высокого уровня (таблицы данных, формы, оверлеи, навигацию) и при необходимости допускает глубокую настройку.

## Основные технологии {#core-technologies}

### Reka UI

Компоненты Bitrix24 UI построены на [Reka UI](https://reka-ui.com/):

- **Соответствие WAI-ARIA**: следует [рекомендациям WAI-ARIA](https://reka-ui.com/docs/overview/accessibility), с правильной семантикой и ролями
- **Навигация с клавиатуры**: встроенная поддержка клавиатуры в сложных компонентах, таких как вкладки и диалоги
- **Управление фокусом**: фокус переходит в зависимости от действий пользователя
- **Доступные подписи**: абстракции, которые упрощают подписывание элементов управления для скринридеров

### Tailwind CSS

Bitrix24 UI использует последнюю версию [Tailwind CSS](https://tailwindcss.com/), которая даёт заметные улучшения:

- **Быстрая сборка**: полная сборка до 5 раз быстрее, инкрементальная — более чем в 100 раз
- **Единый набор инструментов**: встроенная обработка импортов, вендорные префиксы и преобразование синтаксиса
- **Настройка в CSS**: конфигурация и расширение прямо в CSS, без JavaScript
- **Современные возможности веба**: контейнерные запросы, каскадные слои, цвета широкого охвата и другое

### Tailwind Variants

Bitrix24 UI использует [Tailwind Variants](https://www.tailwind-variants.org/) для мощной дизайн-системы:

- **Динамические стили**: гибкие варианты компонентов с мощным API
- **Типобезопасность**: полная поддержка TypeScript с автодополнением
- **Разрешение конфликтов**: эффективное объединение конфликтующих стилей

## Ключевые возможности {#key-features}

### Интеграция с экосистемой {#ecosystem-integration}

Bitrix24 UI совместим с SSR и без лишних усилий встраивается в экосистему Nuxt (в Vue эти возможности тоже работают, но требуют дополнительной настройки):

- [**@bitrix24/b24icons**](https://bitrix24.github.io/b24icons/): иконки Bitrix24 для веб-приложений
- [**Цветовая схема**](/docs/getting-started/integrations/color-mode/): тёмная и светлая тема с автоопределением
- [**i18n**](/docs/getting-started/integrations/i18n/): локализация компонентов на 50+ языков
- [**Content**](/docs/getting-started/integrations/content/): красивая типографика из коробки

### Совместимость с Vue (Nuxt по желанию) {#vue-compatibility-nuxt-optional}

Bitrix24 UI работает в любом Vue-проекте, не только в Nuxt. Достаточно добавить в конфигурацию плагины Vite и Vue:

- **Автоимпорт**: компоненты и композаблы импортируются автоматически и доступны глобально
- **Дизайн-система**: полная поддержка тем — настраиваемые цвета, размеры, варианты и другое
- **Удобство разработки**: полная поддержка TypeScript с IntelliSense и автодополнением

::tip{to="/docs/getting-started/installation/vue/" aria-label="Руководство по установке во Vue"}
Как установить и настроить Bitrix24 UI в Vue-проекте, описано в **руководстве по установке во Vue**.
::

### Поддержка TypeScript {#typescript-support}

Bitrix24 UI глубоко интегрирован с TypeScript, что упрощает разработку:

- **Автодополнение**: для всех пропсов, слотов и событий компонентов
- **Обобщённые компоненты**: на основе [Vue Generics](https://vuejs.org/api/sfc-script-setup.html#generics)
- **Типобезопасные темы**: в `app.config.ts`
- **IntelliSense**: во всей кодовой базе

## FAQ

::accordion

:::accordion-item{label="Чем Bitrix24 UI отличается от Nuxt UI?"}
По сути, ничем. Bitrix24 UI основан на Nuxt UI, но оформлен в общем стиле Bitrix24.
:::

:::accordion-item{label="Bitrix24 UI бесплатный?"}
Да. Bitrix24 UI полностью бесплатен и распространяется с открытым исходным кодом по лицензии MIT. Все 130+ компонентов доступны каждому.
:::

:::accordion-item{label="Можно ли использовать Bitrix24 UI во Vue без Nuxt?"}
Да. Хотя библиотека оптимизирована под Nuxt, в обычных Vue-проектах она отлично работает через наш плагин для Vite. Начать можно с [руководства по установке](/docs/getting-started/installation/vue/).
:::

:::accordion-item{label="Будет ли Bitrix24 UI работать с другими CSS-фреймворками, например UnoCSS?"}
Нет. Bitrix24 UI рассчитан только на Tailwind CSS. Поддержка UnoCSS потребовала бы серьёзных изменений в архитектуре из-за другого именования классов.
:::

:::accordion-item{label="Как Bitrix24 UI обеспечивает доступность?"}
Благодаря интеграции с [Reka UI](https://reka-ui.com/docs/overview/accessibility) компоненты получают ARIA-атрибуты автоматически, поддерживают навигацию с клавиатуры, управление фокусом и скринридеры. Это надёжная основа, но проверять доступность в своём сценарии всё равно нужно.
:::

:::accordion-item{label="Как тестируется Bitrix24 UI?"}
Надёжность обеспечивают более 1000 тестов на Vitest, которые покрывают основную функциональность и доступность.
:::

:::accordion-item{label="Готов ли Bitrix24 UI к продакшену?"}
Да. Bitrix24 UI используют в продакшене тысячи приложений; у библиотеки обширные тесты, регулярные обновления и активная поддержка.
:::

:::accordion-item{label="Можно ли импортировать из `@bitrix24/b24ui/utils`?"}
Импорт сработает, но считайте этот путь внутренним. Подпути `./utils` и `./utils/*` нужны, чтобы компоненты и модуль Nuxt могли обращаться к своим помощникам через границы сборки. Это не поддерживаемый публичный API: он не документирован и меняется без периода устаревания и без повышения мажорной версии.

Всё, что предназначено для вашего приложения, уже доступно: сами компоненты и автоимпортируемые композаблы из раздела [Composables](/docs/composables/use-overlay/). Если нужное есть только в `utils`, [создайте issue](https://github.com/bitrix24/b24ui/issues): такой пробел лучше закрыть правильно, чем обходить.
:::

::
