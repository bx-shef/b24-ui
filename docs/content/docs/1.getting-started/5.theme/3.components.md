## Tailwind Variants

Компоненты Bitrix24 UI стилизуются через API [Tailwind Variants](https://www.tailwind-variants.org/): с его помощью удобно создавать варианты и управлять стилями компонентов.

### Слоты {#slots}

У компонента может быть несколько слотов (`slots`): каждый соответствует отдельному HTML-элементу или части компонента. Слоты позволяют гибко вставлять содержимое и задавать стили.

Возьмём в качестве примера компонент [Card](/docs/components/card/), у которого несколько слотов:

::code-group

```ts [src/theme/card.ts]
export default {
  slots: {
    root: 'bg-(--ui-color-design-filled-bg) border border-(--ui-color-design-filled-stroke) border-(length:--ui-design-filled-stroke-weight) text-(--ui-color-design-filled-content)',
    header: 'p-[24px] sm:px-[22px] sm:py-[15px]',
    body: 'p-[24px] sm:px-[22px] sm:py-[15px]',
    footer: 'p-[24px] sm:px-[22px] sm:py-[15px]'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <div :class="b24ui.root({ class: [props.b24ui?.root, props.class] })">
    <div :class="b24ui.header({ class: props.b24ui?.header })">
      <slot name="header" />
    </div>

    <div :class="b24ui.body({ class: props.b24ui?.body })">
      <slot />
    </div>

    <div :class="b24ui.footer({ class: props.b24ui?.footer })">
      <slot name="footer" />
    </div>
  </div>
</template>
```

::

У некоторых компонентов слотов нет: они состоят из одного корневого элемента. Тогда в теме определён только слот `base`, как, например, у компонента [Container](/docs/components/container/):

::code-group

```ts [src/theme/container.ts]
export default {
  base: 'w-full max-w-(--b24ui-container-width) mx-auto px-4 sm:px-6 lg:px-8'
}
```

```vue [src/runtime/components/Container.vue]
<template>
  <div :class="container({ class: props.class })">
    <slot />
  </div>
</template>
```

::

::warning
У компонентов без слотов нет [пропса `b24ui`](#b24ui-prop): переопределить стили можно только [пропсом `class`](#class-prop).
::

### Варианты {#variants}

Компоненты поддерживают варианты (`variants`): они динамически меняют стили разных слотов в зависимости от пропсов компонента.

Например, компонент [Avatar](/docs/components/avatar/) управляет внешним видом через вариант `size`:

```ts [src/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'air-secondary-accent inline-flex items-center justify-center shrink-0 select-none rounded-full align-middle bg-(--ui-color-base-8) ring ring-(--ui-color-base-7)',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-[28px] text-(length:--ui-font-size-xs)/(--ui-font-line-height-reset)'
      },
      md: {
        root: 'size-[32px] text-(length:--ui-font-size-sm)/(--ui-font-line-height-reset)'
      },
      lg: {
        root: 'size-[42px] text-(length:--ui-font-size-2xl)/(--ui-font-line-height-reset)'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

Так пропс `size` применяет соответствующие стили к слоту `root`:

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/bitrix24.png'
  size: lg
---
::

### Варианты по умолчанию {#default-variants}

Свойство `defaultVariants` задаёт значение каждого варианта по умолчанию, когда пропс не передан.

Например, у компонента [Avatar](/docs/components/avatar/) размер по умолчанию — `md`:

```ts [src/theme/avatar.ts] {19-21}
export default {
  slots: {
    root: 'air-secondary-accent inline-flex items-center justify-center shrink-0 select-none rounded-full align-middle bg-(--ui-color-base-8) ring ring-(--ui-color-base-7)',
    image: 'h-full w-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-[28px] text-(length:--ui-font-size-xs)/(--ui-font-line-height-reset)'
      },
      md: {
        root: 'size-[32px] text-(length:--ui-font-size-sm)/(--ui-font-line-height-reset)'
      },
      lg: {
        root: 'size-[42px] text-(length:--ui-font-size-2xl)/(--ui-font-line-height-reset)'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

### Составные варианты {#compound-variants}

Некоторые компоненты используют свойство `compoundVariants`, чтобы применять классы, когда одновременно выполняется несколько условий вариантов.

Например, компонент [Alert](/docs/components/alert/) с помощью `compoundVariants` применяет классы для определённого сочетания `color` и `inverted`:

```ts [src/theme/button.ts] {27-31}
export default {
  slots: {
    root: [
      'relative overflow-hidden w-full flex',
      'text-(--b24ui-color)',
      'bg-(--b24ui-background)',
      'border-(--b24ui-border-color) border-(length:--b24ui-border-width)',
      'rounded-(--ui-border-radius-md)'
    ].join(' ')
  },
  variants: {
    color: {
      'air-primary': { root: 'style-filled' },
      'air-primary-success': { root: 'style-filled-success' }
    },
    inverted: {
      true: '',
      false: ''
    }
  },
  compoundVariants: [
    {
      inverted: true,
      color: 'air-primary',
      class: {
        root: 'style-filled-inverted'
      }
    },
    {
      inverted: true,
      color: 'air-primary-success',
      class: {
        root: 'style-filled-success-inverted'
      }
    }
  ],
  defaultVariants: {
    color: 'primary',
    variant: 'solid'
  }
}
```

## Настройка темы {#customize-theme}

Внешний вид компонентов Bitrix24 UI можно настроить несколькими способами: сразу для всех компонентов или для каждого по отдельности.

::note
Tailwind Variants объединяет классы через [`tailwind-merge`](https://github.com/dcastil/tailwind-merge), поэтому конфликтов классов можно не опасаться.
::

::tip
Тему каждого компонента можно изучить двумя способами:

- Посмотрите раздел «Тема» (`Theme`) в документации конкретного компонента.
- Откройте исходный код в репозитории GitHub: [`src/theme`](https://github.com/bitrix24/b24ui/tree/main/src/theme).
::

### Глобальная конфигурация {#global-config}

::framework-only
#nuxt
Тему компонента можно переопределить для всех его экземпляров в приложении в `app.config.ts`, с той же структурой, что у самого объекта темы.
#vue
Тему компонента можно переопределить для всех его экземпляров в приложении в `vite.config.ts`, с той же структурой, что у самого объекта темы.
::

Для любого компонента можно изменить [`slots`](#slots), [`variants`](#variants), [`compoundVariants`](#compound-variants) и [`defaultVariants`](#default-variants):

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  b24ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      defaultVariants: {
        size: 'lg'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [vite.config.ts]
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import bitrix24UIPluginVite from '@bxshefby/b24ui-nuxt/vite'

export default defineConfig({
  plugins: [
    vue(),
    bitrix24UIPluginVite({
      b24ui: {
        button: {
          slots: {
            base: 'font-bold'
          },
          defaultVariants: {
            size: 'lg'
          }
        }
      }
    })
  ]
})
```
:::
::

По умолчанию эти классы **объединяются** с собственными классами компонента. Чтобы **заменить** их, задайте слоту функцию: она получает собственные классы слота, так что часть из них можно сохранить:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  b24ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts
bitrix24UIPluginVite({
  b24ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::
::

::warning
**Что именно заменяется, зависит от места, где записана функция-заменитель.**

В глобальной конфигурации она заменяет **собственные** классы слота, поэтому `variants` и `compoundVariants` по-прежнему добавляются сверху: у заменённого `base` остаются классы размера и цвета.

В пропсах [`b24ui`](#b24ui-prop) и [`class`](#class-prop) она выполняется **после** разрешения вариантов и заменяет всё, включая классы вариантов.
::

::framework-only
#nuxt
:::warning
Задавайте слоту функцию только в одном месте. Nuxt объединяет `app.config.ts` всех [слоёв](https://nuxt.com/docs/getting-started/layers) через `defuFn`: он вызывает вашу функцию со значением, которое ключ уже имеет в нижележащем слое, и сохраняет только результат. Bitrix24 UI получает обычную строку, и классы объединяются со стандартными вместо замены.
:::
::

::tip{to="/docs/getting-started/installation/nuxt/#themeunstyled"}
Чтобы убрать классы по умолчанию сразу у всех компонентов, используйте опцию `theme.unstyled`.
::

### Компонент Theme {#theme-component}

Компонент [Theme](/docs/components/theme/) переопределяет слоты и значения пропсов по умолчанию для всех потомков, не затрагивая остальное приложение. Он приоритетнее глобальной конфигурации, а пропсы `b24ui` и `class` приоритетнее него.

Его слоты принимают ту же форму функции `(defaults) => classes`. Она вычисляется там же, где [пропс `b24ui`](#b24ui-prop), поэтому записанная здесь функция заменяет уже вычисленные классы, включая классы вариантов.

### Пропс `b24ui` {#b24ui-prop}

**Слоты** компонента можно переопределить пропсом `b24ui`. Он приоритетнее и глобальной конфигурации, и вычисленных `variants`.

::component-code{slug="button"}
---
prettier: true
ignore:
  - b24ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  useDropdown: true
  size: md
  color: 'air-primary'
  b24ui:
    trailingIcon: 'rotate-90 size-10'
slots:
  default: |

    Button
---
::

::note
В этом примере слот `trailingIcon` получает `size-10`, хотя вариант размера `md` применил бы к нему класс `size-(--ui-btn-icon-size)`.
::

Значением слота может быть и функция, которая **заменяет** классы вместо объединения. Здесь она выполняется после разрешения вариантов, получает полностью вычисленную строку классов слота и заменяет её целиком. В [глобальной конфигурации](#global-config) та же форма заменяет только собственные классы слота — см. примечание там.

```vue
<template>
  <B24Button :b24ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::tip{to="/docs/getting-started/installation/nuxt/#themeunstyled"}
Чтобы убрать классы по умолчанию сразу у всех компонентов, используйте опцию `theme.unstyled`.
::

### Пропс `class` {#class-prop}

Пропс `class` переопределяет классы слота `root` или `base`. Он приоритетнее и глобальной конфигурации, и вычисленных `variants`.

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
В этом примере класс `font-bold` переопределяет класс `font-medium`, который у кнопки по умолчанию.
::
