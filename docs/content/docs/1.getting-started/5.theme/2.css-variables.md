Bitrix24 UI предоставляет утилитарные классы Tailwind CSS для цвета текста, например `text-legend` или `text-description`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[Dimmed]{class="text-dimmed text-sm px-4 py-1.5 inline-block rounded-md"}
[Muted]{class="text-muted text-sm px-4 py-1.5 inline-block rounded-md"}
[Description]{class="text-description text-sm px-4 py-1.5 inline-block rounded-md"}
[Legend]{class="text-legend text-sm px-4 py-1.5 inline-block rounded-md"}
[Label]{class="text-label text-sm px-4 py-1.5 inline-block rounded-md"}

#code
```vue
<template>
  <span class="text-dimmed">Dimmed</span>
  <span class="text-muted">Muted</span>
  <span class="text-description">Description</span>
  <span class="text-legend">Legend</span>
  <span class="text-label">Label</span>
</template>
```

## Контейнер {#container}

CSS-переменная `--b24ui-container-width` задаёт максимальную ширину компонента [Container](/docs/components/container/).

```css
:root {
  --b24ui-container-width: 90rem; /* 1440px */
}
```

## Шапка {#header}

CSS-переменная `--b24ui-header-height` задаёт высоту компонента [Header](/docs/components/header/).

```css
:root {
  --b24ui-header-height: 3.625rem;
}
```

::tip
Значение можно изменить в `main.css`, чтобы высота шапки была одинаковой во всём приложении:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@bitrix24/b24ui-nuxt";

:root {
  --b24ui-container-width: 90rem;
}
```
::

## График :badge{label="2.15+" class="align-text-top"} {#chart}

Компонент [Chart](/docs/components/chart/) красит серии шестью CSS-переменными по порядку. Каждая указывает на акцентный токен air, поэтому палитра сама следует контекстам light, dark, edge-light и edge-dark:

```css
:root {
  --b24ui-chart-1: var(--ui-color-accent-main-primary);
  --b24ui-chart-2: var(--ui-color-accent-main-success);
  --b24ui-chart-3: var(--ui-color-copilot-accent-primary);
  --b24ui-chart-4: var(--ui-color-accent-main-warning);
  --b24ui-chart-5: var(--ui-color-accent-main-alert);
  --b24ui-chart-6: var(--ui-color-collab-accent-primary);
}
```

::tip
Эти CSS-переменные можно изменить в файле `main.css`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@bitrix24/b24ui-nuxt";

:root {
  --b24ui-chart-2: var(--ui-color-palette-green-50);
}
```
::

## Тело страницы {#body}

Bitrix24 UI применяет классы по умолчанию к элементу `<body>`{lang="html"} вашего приложения, чтобы оформление было единым в режимах light, edge-light, edge-dark и dark:

```css
body {
  scrollbar-gutter: stable;
  background: var(--air-theme-background);
  @apply antialiased font-(family-name:--ui-font-family-system) text-legend scheme-light dark:scheme-dark edge-light:scheme-light edge-dark:scheme-light
}
```
