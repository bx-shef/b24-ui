## Tailwind CSS

В Tailwind CSS конфигурация живёт в CSS: дизайн-токены задаются директивой [`@theme`](https://tailwindcss.com/docs/functions-and-directives#theme-directive) прямо в стилях. Тема получается переносимой, удобной в поддержке и лёгкой в настройке.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@bxshefby/b24ui-nuxt";

@theme {
  /* Здесь ваши дизайн-токены */
}
```

::note{to="https://tailwindcss.com/docs/theme/" target="_blank"}
Все доступные варианты настройки переменных темы — в документации Tailwind CSS.
::

::tip
В Tailwind CSS v4 изменён [Preflight](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor): у кнопок `cursor: default` вместо `cursor: pointer`, как в браузерах по умолчанию. Чтобы вернуть курсор-указатель везде, добавьте в CSS такие базовые стили:

```css [app/assets/css/main.css]
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

::

### Контрольные точки {#breakpoints}

Переменные темы `--breakpoint-*` позволяют [настроить контрольные точки](https://tailwindcss.com/docs/responsive-design#customizing-your-theme).

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@bxshefby/b24ui-nuxt";

@theme {
  --breakpoint-3xl: 1920px;
  --breakpoint-4xl: 2560px;
  --breakpoint-5xl: 3840px;
}
```

### Высота всплывающих окон :badge{label="2.14+" class="align-text-top"} {#popup-height}

Две переменные темы ограничивают высоту всплывающего окна. Это верхние пределы,
а не фиксированные высоты: если popper сообщает, сколько места доступно, компонент
берёт меньшее из двух значений, поэтому окно у края экрана уменьшается и прокручивает
содержимое, а не вылезает за границы. Исключение — `Select` с
`content.position="item-aligned"`: popper не сообщает там доступную высоту,
и действует только верхний предел.

| Переменная | По умолчанию | Применяется к |
|---|---|---|
| `--max-height-popup-list` | `40rem` | `Select`, `SelectMenu`, `InputMenu` — прокручиваемые списки результатов |
| `--max-height-popup-menu` | `40vh` | `DropdownMenu`, `ContextMenu`, а также меню слэш-команд, упоминаний и эмодзи в редакторе |

Переменные разделены намеренно. Список ограничен в абсолютных единицах, потому что
удобная длина списка не зависит от окна; меню ограничено относительно области
просмотра, чтобы не занимать весь экран. Увеличив автодополнение, вы не должны
изменить размер контекстных меню.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@bxshefby/b24ui-nuxt";

@theme {
  /* Показывать больше результатов до прокрутки */
  --max-height-popup-list: 56rem;
  /* Оставить меню действий короче */
  --max-height-popup-menu: 30vh;
}
```

::note
Переопределение меняет все всплывающие окна такого вида. Чтобы ограничить один
компонент, передайте класс через его пропс `b24ui`.
::

### Семантические цвета {#semantic-colors}

| Цвет | Назначение |
|---|---|
| **Primary** | **Элементы с сильным акцентом и основные состояния** |
| air-primary | Главные призывы к действию, активные состояния, основной брендинг |
| air-primary-success | Положительные результаты, выполненные задачи, сообщения об успехе |
| air-primary-alert | Критические ошибки, необратимые действия, важные предупреждения |
| air-primary-copilot | Акценты для AI-функций и работы с ассистентом |
| air-primary-warning | Предостережения, задержки статусов, элементы, требующие внимания |
| **Secondary** | **Средний акцент и функциональная поддержка** |
| air-secondary | Второстепенные действия, альтернативные кнопки, фоны интерфейса |
| air-secondary-alert | Мягкие состояния ошибки и некритичная обратная связь о необратимых действиях |
| air-secondary-accent | Общие информационные выделения и системные уведомления |
| air-secondary-accent-1 | Дополнительная цветовая кодировка для категорий и визуализации данных |
| air-secondary-accent-2 | Вторичная кодировка для визуальной группировки и разнообразия |
| air-secondary-no-accent | Нейтральные функциональные состояния без цветового смысла |
| **Третичные и служебные** | **Слабый акцент и специальные случаи** |
| air-tertiary-accent | Едва заметные интерактивные состояния и слабое выделение фона |
| air-tertiary-no-accent | Границы, второстепенный текст, малозаметные разделители |
| air-selection | Состояния выбора, индикаторы фокуса, выделенные элементы |
| air-boost | Яркие маркетинговые акценты и функции, которые нужно заметить |
