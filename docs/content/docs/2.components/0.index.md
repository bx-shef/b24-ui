## Раскладка {#layout}

Базовые структурные компоненты: организуют раскладку приложения и задают единую основу интерфейса.

:components-list{category="layout"}

## Элементы {#element}

Основные строительные блоки интерфейса: кнопки, бейджи, аватары, иконки и другие базовые элементы для понятного и единообразного опыта.

:components-list{category="element"}

## Формы {#form}

Компоненты форм для ввода данных: текстовые поля, списки выбора, чекбоксы, группы переключателей, переключатели, слайдеры и полноценная валидация форм.

:components-list{category="form"}

## Данные {#data}

Компоненты для показа и организации данных: таблицы, аккордеоны, карусели, таймлайны, деревья и профили пользователей.

:components-list{category="data"}

## Навигация {#navigation}

Компоненты навигации: меню, хлебные крошки, постраничная навигация, вкладки, пошаговые мастера, ссылки и командные палитры.

:components-list{category="navigation"}

## Оверлеи {#overlay}

Плавающие элементы поверх основного содержимого: модальные окна, поповеры, подсказки, шторки, боковые панели и контекстные меню.

:components-list{category="overlay"}

## Страницы {#page}

Готовые маркетинговые и контентные секции для лендингов, блогов, страниц с тарифами и других материалов.

:components-list{category="page"}

## Дашборд {#dashboard}

Специальные компоненты для динамичных дашбордов: панели с изменяемым размером, сворачиваемые боковые колонки, панели инструментов и поиск.

:components-list{category="dashboard"}

::callout{color="air-secondary-accent" icon-name="GitHubIcon"}
Реальный пример — шаблоны дашборда на [`Nuxt`](https://github.com/bitrix24/templates-dashboard) и [`Vue`](https://github.com/bitrix24/templates-dashboard-vue) на GitHub.
::

## AI-чат {#ai-chat}

Компоненты для диалоговых интерфейсов и чат-ботов на основе [Vercel AI SDK](https://ai-sdk.dev/).

:components-list{category="chat"}

## Редактор {#editor}

Компоненты для текстового редактора с поддержкой Markdown, HTML и JSON на основе [TipTap](https://tiptap.dev/).

:components-list{category="editor"}

## Content

Компоненты, которые работают с [Content](/docs/getting-started/integrations/content/) на сайтах документации: оглавление, поиск, деревья навигации и ссылки на соседние страницы.

:components-list{category="content"}
