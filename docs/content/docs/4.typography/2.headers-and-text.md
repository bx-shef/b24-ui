## Заголовки {#headings}

Заголовки структурируют содержимое и облегчают чтение.

Если у заголовка есть `id`, его можно обернуть в якорную ссылку: для `H2`, `H3` и `H4` при наведении показывается значок решётки, чтобы читатели могли ссылаться прямо на раздел.

По умолчанию якорные ссылки отключены. Компонент [`Theme`](/docs/components/theme/) с пропсом `anchor` включает или выключает их для части приложения:

```vue
<template>
  <B24Theme :props="{ prose: { h2: { anchor: true }, h3: { anchor: true }, h4: { anchor: true } } }">
    <!-- ваш отрисованный markdown -->
  </B24Theme>
</template>
```

::note
При использовании `@nuxt/content` якорные ссылки по умолчанию включены для `H2`, `H3` и `H4`. Их [генерацию](https://content.nuxt.com/docs/getting-started/configuration#anchorlinks) (например, чтобы отключить в интерфейсах ИИ-чатов) и [генерацию оглавления](https://content.nuxt.com/docs/getting-started/configuration#toc) можно настроить в `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    renderer: {
      anchorLinks: false
    },
    build: {
      markdown: {
        toc: {
          depth: 3
        }
      }
    }
  }
})
```
::

## Ссылки {#links}

Чтобы создать ссылку, заключите её текст в квадратные скобки, а адрес — в круглые. Подходит для внешних и внутренних ссылок.

::tabs{class="gap-0"}

::code-preview{label="Предпросмотр" class="[&>div]:*:my-0"}
[Документация Bitrix24](https://bitrix24.com)

#code

```mdc
[Документация Bitrix24](https://bitrix24.com)
```

::

:component-theme{slug="a" prose label="Тема"}

::

## Цитаты {#blockquotes}

> Bitrix24 UI автоматически подстраивается под настройки темы, обеспечивая единую типографику во всём приложении.
