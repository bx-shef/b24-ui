## Списки {#lists}

Markdown поддерживает маркированные, нумерованные и вложенные списки.

### Маркированные списки {#unordered-lists}

Маркированные списки подходят для элементов без определённого порядка. Каждый элемент начинается со знака `-`.

::tabs{class="gap-0"}

::code-preview{label="Предпросмотр" class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Элемент списка.
- Ещё один элемент списка.
- Последний элемент списка.

#code

```mdc
- Элемент списка.
- Ещё один элемент списка.
- Последний элемент списка.
```

### Нумерованные списки {#ordered-lists}

Нумерованные списки нужны, когда важен порядок элементов, например шагов процесса. Каждый элемент начинается с номера.

::tabs{class="gap-0"}

::code-preview{label="Предпросмотр" class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Элемент списка.
2. Ещё один элемент списка.
3. Последний элемент списка.

#code

```mdc
1. Элемент списка.
2. Ещё один элемент списка.
3. Последний элемент списка.
```

### Вложенные списки {#nested-lists}

Вложенные пункты позволяют строить иерархические списки для сложных структур. Подпункты сдвигаются на четыре пробела.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

- Элемент списка.
  - Вложенный элемент списка.
  - Ещё один вложенный элемент списка.
- Ещё один элемент списка.
  - Ещё один вложенный элемент
    - Элемент глубокой вложенности
    - Ещё один элемент глубокой вложенности
  - Возврат на второй уровень

#code

```mdc
- Элемент списка.
  - Вложенный элемент списка.
  - Ещё один вложенный элемент списка.
- Ещё один элемент списка.
  - Ещё один вложенный элемент
    - Элемент глубокой вложенности
    - Ещё один элемент глубокой вложенности
  - Возврат на второй уровень
```

::

### Смешанные списки {#mixed-lists}

Нумерованные и маркированные списки можно сочетать для сложных иерархий.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

1. Первый основной шаг
   - Подтребование A
   - Подтребование B
2. Второй основной шаг
   - Ещё один подпункт
   - Последний подпункт
3. Последний шаг

#code

```mdc
1. Первый основной шаг
   - Подтребование A
   - Подтребование B
2. Второй основной шаг
   - Ещё один подпункт
   - Последний подпункт
3. Последний шаг
```

## Таблицы {#tables}

Таблицы наглядно показывают структурированные данные в строках и столбцах. Они удобны для сравнения данных и перечисления свойств.

::tabs{class="gap-0"}

::code-preview{label="Предпросмотр" class="[&>div]:*:my-0 [&>div]:*:w-full"}

| Пропс   | По умолчанию | Тип                   |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |

#code

```mdc
| Пропс   | По умолчанию | Тип                   |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
