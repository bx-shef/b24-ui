Bitrix24 UI оформляет **Prose-компоненты**, которые предоставляет [@nuxtjs/mdc](https://github.com/nuxt-modules/mdc), в едином красивом стиле. Модуль Nuxt MDC превращает markdown в семантические компоненты Vue, а Bitrix24 UI применяет к ним свою дизайн-систему, поэтому содержимое автоматически подстраивается под тему приложения.

::note{to="/docs/getting-started/integrations/content/"}
Установка и настройка Nuxt Content описаны в руководстве по **интеграции с Content**.
::

## Использование {#usage}

Типографика строится на prose-компонентах Nuxt MDC и оформляется Bitrix24 UI. Стилизованное содержимое можно отрисовать несколькими способами:

1. **Отрисовка markdown** — компонент ContentRenderer или MDC отрисовывает markdown с автоматической prose-стилизацией
2. **Прямое использование во Vue** — prose-компоненты импортируются и используются прямо в шаблонах Vue

### С ContentRenderer {#with-contentrenderer}

Самый простой способ: при использовании компонента [`<ContentRenderer>`](https://content.nuxt.com/components/content-renderer) markdown стилизуется автоматически:

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

::note
Nuxt MDC автоматически сопоставляет каждому элементу markdown стилизованный prose-компонент:
- `# Heading` → `<ProseH1>` (с доступными якорными ссылками)
- `**bold**` → `<ProseStrong>` (стилизуется по вашей теме)
- `` `code` `` → `<ProseCode>` (с подсветкой синтаксиса)
- ...остальной синтаксис markdown отрисовывается соответствующими prose-компонентами, что обеспечивает единый дизайн и темизацию.
::

### С компонентом MDC {#with-mdc-component}

Если нужно больше контроля над отрисовкой markdown, используйте компонент [`<MDC>`](https://github.com/nuxt-modules/mdc):

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-modules/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::note
Этот способ подходит, когда нужно:
- отрисовывать markdown из внешних источников, например API или баз данных;
- подставлять в markdown динамические или собственные данные;
- строить гибкие динамические системы контента;
- безопасно обрабатывать и показывать markdown, написанный пользователями.
::

### С компонентами Prose {#with-prose-components}

Для максимального контроля используйте prose-компоненты прямо в шаблонах Vue:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

### С явными импортами :badge{label="2.15+" class="align-text-top"} {#with-explicit-imports}

Prose-компоненты также экспортируются из `@bxshefby/b24ui-nuxt/components/prose`. Можно импортировать нужные компоненты явно, не полагаясь на автоимпорт:

```vue
<script setup lang="ts">
import { ProseTable, ProseThead, ProseTbody, ProseTr, ProseTh, ProseTd } from '@bxshefby/b24ui-nuxt/components/prose'
</script>

<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>color</ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

::note
Опция `prose` должна быть включена: она генерирует тему prose-компонентов.
::
