## Блоки кода {#code-blocks}

Блоки кода отрисовывает компонент `ProsePre` из `@nuxtjs/mdc`, а [подсветку кода](https://content.nuxt.com/docs/files/markdown#code-highlighting) под капотом выполняет [Shiki](https://github.com/shikijs/shiki).

Пропс `copy` со значением `false` скрывает кнопку копирования, а пропсы [Button](/docs/components/button/) позволяют её настроить.

::tabs{class="gap-0"}

::code-preview{label="Предпросмотр" class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts
export default defineNuxtConfig({
  modules: ['@bxshefby/b24ui-nuxt']
})
```

#code

````mdc
```ts
export default defineNuxtConfig({
  modules: ['@bxshefby/b24ui-nuxt']
})
```
````

### Язык {#language}

Подсветка синтаксиса доступна для десятков языков программирования.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'
}
</script>

<template>
  <div>
    <h1>{{ message }}</h1>
    <B24Button @click="updateMessage">
      Click me
    </B24Button>
  </div>
</template>
```

#code

````html
```vue
<script setup lang="ts">
const message = ref('Hello World!')

function updateMessage() {
  message.value = 'Button clicked!'

<template>
  <div>
    <h1>{{ message }}</h1>
    <B24Button @click="updateMessage">

    </B24Button>
  </div>
</template>
```
````

::

::tip
Для подсветки синтаксиса по умолчанию используются темы VSCode `material-theme-lighter` (светлая) и `material-theme-palenight` (тёмная).
::

### Имя файла {#filename}

Блоки кода показывают имя файла и автоматически подбирают иконку.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@bxshefby/b24ui-nuxt']
})
```

````mdc
```ts [nuxt.config.ts]
````

### Подсветка строк {#line-highlighting}

Подсветка отдельных строк привлекает внимание к важным частям.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@bxshefby/b24ui-nuxt'], // Эта строка подсвечена
  css: ['~/assets/css/main.css']
})
```

#code

````mdc
```ts [nuxt.config.ts] {2}
export default defineNuxtConfig({
  modules: ['@bxshefby/b24ui-nuxt'], // Эта строка подсвечена
  css: ['~/assets/css/main.css']
})
```
````

### Различия в коде {#code-diff}

Язык `diff` показывает изменения между версиями кода.

::code-preview{class="[&>div]:*:my-0 [&>div]:*:w-full"}

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@bitrix24/b24ui'
+   '@bxshefby/b24ui-nuxt'
  ]
})
```

#code

````mdc
```diff [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
-   '@bitrix24/b24ui'
+   '@bxshefby/b24ui-nuxt'
  ]
})
```
````

### Цвет {#color}

Пропс `color` меняет цвет встроенного кода. По умолчанию `air-secondary`.

::code-preview{class="[&>div]:*:my-0"}
`inline code`{color="air-primary-alert"}

#code

```mdc
`inline code`{color="air-primary-alert"}
```
