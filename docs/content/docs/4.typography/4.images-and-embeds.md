### Увеличение {#zoom}

По умолчанию изображения можно увеличивать: по клику изображение открывается в модальном оверлее с плавным переходом, и пользователь может рассмотреть детали.

Чтобы отключить увеличение для конкретного изображения, добавьте атрибут `:zoom="false"`.

::code-preview{class="[&>div>p]:my-0"}
![Изображение без увеличения](/b24ui/assets/demo/b24rich_new.png){:zoom="false"}

#code

```mdc
![Изображение без увеличения](/b24ui/assets/demo/b24rich_new.png){:zoom="false"}
```

::
